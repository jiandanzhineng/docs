# 硬件固件烧录说明

## 方式一：USB 有线烧录

1. 安装驱动 
    1. CH340串口芯片驱动：[https://www.wch.cn/downloads/CH341SER_EXE.html](https://www.wch.cn/downloads/CH341SER_EXE.html)
    2. CH343串口芯片驱动：[https://www.wch.cn/downloads/CH343SER_EXE.html](https://www.wch.cn/downloads/CH343SER_EXE.html)
    3. 下载后直接运行即可
2. 下载flash tool
    1. [https://dl.espressif.com/public/flash_download_tool.zip](https://dl.espressif.com/public/flash_download_tool.zip)
    2. 解压运行
    3. 使用说明：
    4. [https://docs.espressif.com/projects/esp-test-tools/zh_CN/latest/esp32/production_stage/tools/flash_download_tool.html#id5](https://docs.espressif.com/projects/esp-test-tools/zh_CN/latest/esp32/production_stage/tools/flash_download_tool.html#id5)
    5. 说明第三步中需要修改COM口 其他部分无需修改
3. 下载固件
    1. [https://github.com/jiandanzhineng/hardware/releases/latest](https://github.com/jiandanzhineng/hardware/releases/latest)
    2. ![1768981515944-c052b509-6ae3-41d5-b212-367666940cfd.png](./img/IpJdu5RTAcw-LC13/1768981515944-c052b509-6ae3-41d5-b212-367666940cfd-449925.png)
    3. 根据设备类型下载固件 （下载带merged字样的固件）电击-DIANJI 气压传感器-QIYA 偏轴电机控制器-TD01 距离感应器-QTZ
    4. 使用工具烧录到设备0x0位置即可

## 方式二：OTA 无线更新（推荐）

如果设备已连接 WiFi 并在线，可通过控制客户端进行无线固件更新，无需 USB 接线。

1. 打开电脑客户端或手机客户端，进入**设备管理**
2. 找到需要更新的设备，点击**固件更新**（或"检查更新"）
3. 客户端会自动比对设备当前版本与最新固件版本
4. 如有新版本，点击**更新**即可
5. 更新过程：客户端通过 MQTT 向设备下发更新指令 → 设备自动下载固件 → 写入并重启
6. 更新完成后设备会自动重新上线

**注意：**
- OTA 更新需要设备已连接 WiFi 且在线上
- 更新过程中请勿断开设备电源
- 支持批量更新多台设备
- 固件下载地址：[https://github.com/jiandanzhineng/hardware/releases/latest](https://github.com/jiandanzhineng/hardware/releases/latest)
