# 通过控制面板插线更新固件

设备无法联网、OTA 更新失败，或需要重新安装当前固件时，可使用电脑客户端通过 USB 插线烧录。客户端会自动识别设备、下载并校验固件、自动进入下载模式、写入并重启，不需要手动操作 Flash Tool 或按设备按键进入下载模式。

## 更新前准备

- 使用稳定的 USB 数据线将设备接到电脑；只供电的充电线无法更新。
- 更新期间保持电脑和设备供电，不要拔线或关闭客户端页面。
- **烧录会清除设备的 Wi-Fi 配网和绑定信息。** 完成后需要重新配网。

### 首次使用：安装串口驱动

第一次在此电脑上使用 USB 插线更新时，先安装与设备串口芯片对应的 WCH 驱动：

- [CH340/CH341 驱动](https://www.wch.cn/downloads/CH341SER_EXE.html)
- [CH343 驱动](https://www.wch.cn/downloads/CH343SER_EXE.html)

下载后直接运行安装程序。安装完成后重新插拔设备，并在客户端点击「刷新串口」。如果页面提示“检测到 CH34x 设备但驱动未安装”，按提示安装驱动后再刷新即可。

## 客户端自动插线更新

1. 打开控制面板，进入「设备管理」→「设备工具」→「固件更新」，再选择「插线烧录」。
2. 在「连接与识别」中选择设备对应的串口。设备串口通常会带有 CH340、CH343 或 USB-Enhanced-SERIAL 等名称；不要选择电脑自带的 `COM1`。

![在列表中选择已插入设备的串口](./img/wired-firmware-update/01-select-com17.png)

3. 客户端会自动识别设备型号和当前版本，随后显示可用的完整固件、版本和文件大小。自动识别失败时，可在型号下拉框中手动选择正确型号后继续。

![自动识别设备并检查固件](./img/wired-firmware-update/02-device-identified.png)

4. 有新版本时点击「更新固件」；若显示已是最新版本但需要修复或重装，点击「重新刷入」。在确认窗口中核对清除 Wi-Fi 配网和绑定信息的提示，然后点击「开始烧录」。

![确认开始自动烧录](./img/wired-firmware-update/03-confirm-reflash.png)

5. 客户端会自动下载并校验固件、进入下载模式、烧录和重启。整个过程不需要手动进入下载模式；进度条出现前后都不要拔掉 USB 线或关闭页面。

![自动烧录进度](./img/wired-firmware-update/04-flashing-progress.png)

6. 看到“固件烧录成功！设备已重启，请重新配网”即表示完成。重新配网后，再回到设备管理确认设备上线。

![烧录成功](./img/wired-firmware-update/05-flash-success.png)

## 常见情况

### 未检测到串口

确认设备已插入、USB 线支持数据传输，并先完成上方的驱动安装。重新插拔设备后点击「刷新串口」。

### 识别不到型号

等待自动识别结束后，从型号下拉框选择设备的实际型号。若仍无法确认型号，请不要随意刷入其它型号的固件。

### 烧录失败

保持 USB 线连接，先点击「重试烧录」。若仍失败，换用数据线或 USB 接口后重新开始；不要在烧录过程中反复插拔设备。

## OTA 无线更新

如果设备已连接 WiFi 并在线，可通过控制客户端进行无线固件更新，无需 USB 接线。

1. 打开电脑客户端或手机客户端，进入**设备管理**
2. 找到需要更新的设备，点击**固件更新**（或"检查更新"）
3. 客户端会自动比对设备当前版本与最新固件版本
4. 如有新版本，点击**更新**即可
5. 更新过程：客户端通过 MQTT 向设备下发更新指令 → 设备自动下载固件 → 写入并重启
6. 更新完成后设备会自动重新上线

**注意：**
- OTA 更新需要设备已连接 WiFi 且在线上
- 更新过程中请勿断开设备电源
- 支持批量更新多台设备
- 固件下载地址：[https://github.com/jiandanzhineng/hardware/releases/latest](https://github.com/jiandanzhineng/hardware/releases/latest)
