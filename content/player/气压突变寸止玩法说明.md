# 气压突变寸止玩法说明

## 简介

这是一个根据气压变化自动调节震动的寸止玩法：平静时逐渐增强，检测到气压突然抬升时停止震动，等待压力回落并冷却，再开始下一轮。

与三阶段寸止相比，它保留了平静期、中期、边缘期和冷却的循环，但将触发方式改为**短时间内的气压抬升幅度**，并在每次触发后自动校准中间压力，减少慢漏气等基线变化对固定阈值的影响。

| 对比项 | 三阶段寸止 | 气压突变寸止 |
| --- | --- | --- |
| 进入边缘期 | 气压达到设定的临界气压 | 最近一段时间的压力峰值比前一段平均压力高出设定幅度 |
| 压力设置 | 手动设置中间压力和临界气压 | 调整突变窗口、抬升阈值；中间压力每轮自动校准 |
| 调整重点 | 固定压力值是否适合自己 | 突变判定是否过于敏感或迟钝 |

[三阶段寸止玩法说明](./气压寸止玩法3阶段升级版说明.md)

本文参数以游戏 **1.1.2** 的默认配置为准。气压变化只是程序的判定信号，不能直接代表真实身体状态。

:::caution 结束前起飞期
默认最后 **60 秒**不再根据气压触发寸止，也不再进入中期减弱，而是逐渐增强至设定上限。希望整局保持寸止循环时，请在开始前将「结束前起飞期」设为 **0 秒**。
:::

## 所需设备

| 设备映射 | 是否必需 | 作用 |
| --- | --- | --- |
| 气压传感器 | 是 | 提供实时气压读数 |
| TD01刺激器 | 是 | 按游戏目标强度控制震动 |
| 电击惩罚设备 | 否 | 进入边缘期时发起电脉冲 |
| 自动锁 | 否 | 游戏开始上锁，正常结束解锁 |

使用寸止综合设备时，可在气压、震动和电击槽位分别选择同一台支持对应功能的设备；「TD01刺激器」是游戏中的映射名称。未映射电击或自动锁，也可以运行气压与震动的循环。

## 使用说明 {#use_instruction}

1. 完成设备组装，并在正式佩戴前确认气压读数和震动控制正常。
2. 安装客户端并连接设备。
3. 在客户端的游戏库中选择「气压突变寸止」，映射气压传感器和震动设备，再按需要映射电击、自动锁。
4. 设置游戏时长、最大强度和是否启用结束前起飞期。突变检测可先保留默认的 **500 毫秒窗口、1 kPa 抬升阈值**。
5. 启动游戏，观察压力曲线和阶段变化，再按实际触发情况调整参数。

## 游戏流程

**平静期逐渐增强 → 达到中间压力后调节强度 → 气压突变时停止震动 → 压力回落或超时 → 冷却 → 回到平静期。**

气压突变在平静期也能直接触发，不必先经过中期。

### 1. 平静期

游戏从零强度开始，默认每秒增强 **2**，最大强度 **50**。压力达到「中间压力」后进入中期；检测到气压突变时直接进入边缘期。

### 2. 中期刺激

根据当前压力降低目标强度：默认在「中间压力」到「中间压力 + 1 kPa」之间，目标强度从 **20** 逐渐降到 **5**；压力更高时维持下限。

例如中间压力为 **30 kPa**，在没有触发突变的情况下，30 kPa 对应目标强度20，30.5 kPa 对应12.5，31 kPa及以上对应5。实际输出还受最大强度、增强速率和下发间隔限制。

压力低于中间压力时回到平静期；检测到突变时进入边缘期。

### 3. 边缘寸止

进入边缘期后震动归零，并记录一次边缘触发。已映射电击设备时，还会发起一次电脉冲，默认配置为 **20 V、3 秒**。

满足以下任一条件后进入冷却：

- 当前压力低于「触发时记录的前一窗口平均压力 + 0.2 kPa」。
- 边缘期超过最长时长，默认 **5 秒**。

例如触发前的平均压力为30 kPa，回落到30.2 kPa以下即可进入冷却；如果压力一直不回落，达到最长时长后也会进入冷却。

### 4. 冷却延迟

震动继续保持为零，默认等待 **5 秒**。这段时间不再检测新的突变，并记录冷却期间的最低压力，供下一轮自动校准使用。

冷却结束先回到平静期，随后再根据压力决定是否进入中期。恢复强度会参考当前压力与中间压力的差距，并受增强速率限制。

### 5. 起飞期与结束

默认最后60秒进入起飞期，优先退出当前的中期、边缘期或冷却阶段，按平静期的增强规则持续抬升强度。**此时气压突变不会再触发停机寸止。**

游戏时长到达后停止震动和电脉冲，并向已映射的自动锁发送解锁命令。如果起飞期时长大于或等于整局时长，游戏会从一开始就进入起飞期。

## 气压突变怎样判定

默认把最近1秒分成两个连续的半秒窗口：

- **前一窗口**：取再往前0.5秒的平均压力。
- **当前窗口**：取最近0.5秒的最高压力。

当「当前窗口最高压力 - 前一窗口平均压力」达到 **1 kPa**，并且这个比较条件连续成立至少 **100 毫秒**，就触发边缘期。

例如前一窗口平均30 kPa，当前窗口最高31.2 kPa，差值为1.2 kPa，已超过默认阈值；继续满足最短持续时间后即可触发。这里持续的是窗口比较条件，并不要求每个采样点都达到31.2 kPa。

因此，**慢慢升到较高压力不一定触发，而较低压力下的突然抬升也可能触发**。

## 中间压力怎样自动校准

中间压力初始为 **50 kPa**。每次进入边缘期，会从以下数值中取最大值作为新的中间压力：

- 本次触发峰值减去「中间压偏移」，默认减 **1 kPa**。
- 上一轮冷却期间的最低压力加 **1 kPa**。
- 最低值 **1 kPa**。

例如本次峰值31.2 kPa、上一轮冷却最低压力29 kPa，新的中间压力就是30.2 kPa。若上一轮冷却最低压力为30 kPa，则下限会将中间压力抬到31 kPa。

界面的「中间压力微调」每次可增减 **0.1 kPa**，但下一次进入边缘期会重新自动校准。

## 配置说明

以下为程序默认值，不代表适合所有人的使用强度。

### 基础与突变判定

| 参数名称 | 默认值 | 说明 |
| --- | --- | --- |
| 游戏时长 | 20 分钟 | 整局持续时间 |
| 结束前起飞期 | 60 秒 | 最后阶段持续增强，不再触发寸止；设为0关闭 |
| 突变检测窗口 | 500 毫秒 | 每个窗口的宽度；两个窗口合计覆盖最近1秒 |
| 突变抬升阈值 | 1 kPa | 当前窗口峰值与前一窗口均值的最小差值 |
| 突变最短持续 | 100 毫秒 | 窗口比较条件需连续成立的时间 |
| 中间压偏移 | 1 kPa | 自动校准时从触发峰值减去的压力 |
| 边缘期最长时长 | 5 秒 | 压力没有回落时，超时进入冷却 |
| 冷却延迟 | 5 秒 | 边缘期后继续保持零震动的时间 |
| 语音提示 | 开启 | 播报开始、阶段切换、结束等事件 |

### 强度与可选电击

| 参数名称 | 默认值 | 说明 |
| --- | --- | --- |
| TD01最大强度 | 50 | 游戏强度上限，配置范围1至100 |
| 平静期缓升 | 每秒2 | 平静期和起飞期的目标强度增幅 |
| 强度递增上限 | 每秒2 | 实际强度向上变化的速率限制；下降不受此限制 |
| 中期强度下限 | 5 | 压力达到「中间压力 + 偏移」后的目标强度 |
| 中期强度上限 | 20 | 压力等于中间压力时的目标强度，不能超过总上限 |
| 强度随机扰动 | 0% | 平静期目标强度的随机变化幅度；0为关闭 |
| 强度下发间隔 | 2000 毫秒 | 普通强度命令的发送间隔；归零停机不必等待此间隔 |
| 电击强度 | 20 V | 已映射电击设备时，进入边缘期使用的电压 |
| 电击持续 | 3 秒 | 单次电脉冲持续时间 |

## 界面与调节

- **压力曲线**：蓝色实线为压力，红色虚线为震动强度，橙色虚线为中间压力；绿色点标记触发峰值，红色点标记边缘阶段的压力采样。
- **暂停 / 继续**：暂停时停止震动，继续显示气压。恢复后重新收集突变窗口。
- **+10 强度**：临时修改当前目标值，后续仍会由自动规则重新计算，不会提高最大强度上限。
- **电击**：手动发起一次电脉冲，使用配置中的电压和持续时间，需映射电击设备。
- **次数与日志**：查看边缘触发、阶段切换、最近触发峰值等记录。

**暂停不会延长原定结束时间，也不会自动解锁或中断已经发起的电脉冲。** 已发起的电脉冲仍按配置时长结束，不能将暂停当作全部设备的紧急停止。

调整时可参考：

- **频繁误触发**：先检查气路连接和读数是否稳定，再适当提高「突变抬升阈值」或延长「突变最短持续」。
- **明显变化却不触发**：确认气压读数持续更新，且当前不在冷却或起飞期，再适当降低抬升阈值。
- **停得不够久**：增加「冷却延迟」；「边缘期最长时长」仅是等待压力回落的上限，不是固定休息时间。
- **不想最后持续增强**：开始前将「结束前起飞期」设为0秒。

## 安全使用说明

正式佩戴前先确认设备控制正常，从较低强度和较短时长开始，不适时立即停止。电脉冲使用和佩戴要求请遵循现有设备教程，不要让电流流经心脏、头部或躯干。

[设备佩戴与电脉冲注意事项](./寸止玩法二代使用教程.md#operation-steps)

连接自动锁前请确认有独立脱困手段，不能仅依赖程序结束时的自动解锁。
