## 玩法教程

| 玩法 | 所需设备/能力 | 一句话说明 |
| --- | --- | --- |
| [寸止系列怎么选](/docs/player/edging) | 寸止综合设备 | 三种寸止玩法的区别与选择建议 |
| [主机内置寸止（寸止+提肛）](/docs/player/cunzhi01) | 寸止综合设备（气压+震动+电脉冲） | 持续刺激到阈值自动停止，让你保持在边缘状态 |
| [气压寸止玩法（3 阶段升级版）](/docs/player/cunzhi3step) | 寸止综合设备，可选自动锁/OSR6 | 气压越过临界值触发电击，平静-中期-边缘-冷却循环 |
| [气压突变寸止玩法](/docs/player/surge-edging) | 寸止综合设备 | 按短时间气压抬升触发，中间压力每轮自动校准 |
| [提肛训练玩法](/docs/player/kegel-training) | 寸止综合设备 | 放松-提肛循环检测，漏做会被电脉冲提醒 |
| [踮脚惩罚玩法v2](/docs/player/tiptoe-v2) | 寸止综合设备，可选自动锁 | 保持踮脚站立，脚后跟落地即被惩罚 |
| [踮脚提肛训练教程](/docs/player/tiptoe-kegel) | 寸止综合设备 | 同时保持提肛和踮脚的体态训练 |
| [喝水/液体收集解锁玩法](/docs/player/drink-pee-unlock) | 电子秤，可选电脉冲/自动锁 | 按目标喝水或收集液体，达标或超时解锁 |
| [俯卧撑（大概）检测训练游戏](/docs/player/pushup-game) | 距离感应，可选寸止设备/自动锁 | 距离传感器判定俯卧撑次数 |
| [扇贝背单词电击](/docs/player/shanbay-shock) | 电脉冲设备 | 背错单词就电击的背单词玩法 |
