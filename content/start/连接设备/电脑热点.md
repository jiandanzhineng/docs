# 电脑热点（电脑连设备）

电脑客户端控制自家设备只能走 WiFi/局域网，不能像手机那样蓝牙直连；电脑端的蓝牙只用于其他品牌设备（如 DGLAB 等）。最简单的方式是让电脑开热点，设备会自动连上。

1. 启用电脑热点，WiFi 名称为 `easysmart`，密码为 `11111111`，频段必须是 **2.4G**。
2. 如果设备连上了 WiFi 但客户端里没有设备，关闭电脑防火墙。
3. 启动设备，设备启动后约 15~30 秒会自动连接到电脑。

## 注意

- 设备如果之前连过 5G WiFi，可能设置成 2.4G 后仍在 5G 频段；此时需要让设备连一次 2.4G WiFi（或网线连接）再试。
- 设备默认会自动连接名称为 `easysmart`、密码为 `11111111` 的 WiFi，不想配网时可以直接用这个默认 WiFi。

没有条件开电脑热点，可以让设备[配网到家里 WiFi](/docs/other/wifi-config/app)，再在客户端启用 mDNS 通过局域网连接，详见 [PC 客户端](/docs/player/new-phone-client#无电脑热点情况使用方式)。
