# 客户端下载

## 安卓客户端 {#安卓客户端}

安卓下载链接：https://dl.undersilicon.cn/apk/latest/app-release.apk

手机添加设备（以 cunzhi01 为例）：

- 开启设备，蓝灯闪烁；打开客户端点「添加设备」或右上角加号。
- 按提示选择设备并点「完成」，添加成功即已连接（蓝灯常亮几秒后熄灭）。
- 完整截图步骤见[蓝牙直连（手机）](/docs/start/connect/ble)。

### 使用指南

1. 下载地址：[https://firmware.undersilicon.cn/control-panel/stable/UnderSilicon.zip](https://firmware.undersilicon.cn/control-panel/stable/UnderSilicon.zip)
2. **请解压后安装 （解压失败可以安装 [7zip](https://www.7-zip.org/download.html) 之后用该软件解压**）
3. **启动客户端**
4. **启用电脑热点，设置 WiFi 名为 easysmart、密码为 11111111，频段选 2.4G。启动设备后约 15-30 秒会自动连接；如果客户端里没有设备，关闭电脑防火墙。**
   完整步骤和常见问题（5G 频段）见[电脑热点（电脑连设备）](/docs/start/connect/hotspot)；开不了热点见[配网到家里 WiFi](/docs/start/connect/pc-home-wifi)。
5. **可以开始愉快玩耍啦**

### 无电脑热点情况使用方式 {#无电脑热点情况使用方式}

没有条件开电脑热点时，把设备配网到家里的 2.4G WiFi，客户端通过 mDNS 在局域网里连接设备，完整步骤见[配网到家里 WiFi](/docs/start/connect/pc-home-wifi)。
