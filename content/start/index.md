# 第一次使用

:::info
单人游玩前，请先阅读 [安全须知](/docs/player/solo-safety)：单人游玩必须有设备之外的脱困手段。
:::

第一次使用按下面三步走即可。

## 1. 下载安装客户端

手机安装[安卓客户端](/docs/player/new-phone-client)，电脑安装 [Windows 客户端](/docs/pc-client)；iPhone、鸿蒙分别见 [iOS 客户端](/docs/player/ios-client)、[鸿蒙客户端](/docs/player/harmonyos-client)。

## 2. 连接设备

手机日常用蓝牙直连：开启设备、蓝灯闪烁，打开客户端点「添加设备」即可。用电脑或需要 WiFi 时，先看[怎么选连接方式](/docs/start/connect)。

## 3. 选玩法开始

打开[玩法总览](/docs/player)挑一个玩法，按教程完成设备映射和参数配置后即可开始。
