# 寸止综合设备（第二代）

> 失控边缘的极致掌控 —— 告别漏气，无限续航，多模式沉浸，手机一键即玩。

寸止综合设备是「硅基之下」的旗舰主机，把**气压传感、震动刺激、电脉冲**三合一集成到一台主机上，配合手机 / 电脑客户端，单机即可玩转寸止、提肛、踮脚等多种玩法。

## 核心卖点

- **精准触发**：高精压力测量，100ms 极速反应
- **持久无忧**：2000mAh 大电池，专属稳压芯片，电量再低刺激不减
- **无感佩戴**：29mm 超细肛塞 + 绑腿隐秘设计
- **一机多玩**：寸止 / 提肛 / 踮脚，支持多设备联动

## 相比上一代的升级

| 维度 | 旧方案 | 第二代 |
| :--- | :--- | :--- |
| 游玩时长 | 气囊漏气，约 20 分钟 | 固态高精压感，**无限时长** |
| 入体体验 | 35mm | 29mm（直径下降 18%） |
| 续航 | 普通电池 | 2000mAh（提升 300%） |

## 版本与配件

### 版本介绍

【完整版】寸止设备（气压+震动+电击）+男用单品+踮脚传感器

【寸止版】寸止设备（气压+震动+电击）+男用单品

【OSR6版】寸止设备（气压+震动+电击）

配件：踮脚传感器、肛塞压力传感器。女用另需炮机 + [炮机控制器](/docs/device/reciprocating-motor)。

**包装内不含充电线**，主机用普通手机充电线（Type-C）即可充电，无需单独购买。
