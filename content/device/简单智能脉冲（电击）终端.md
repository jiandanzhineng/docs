# 简单智能脉冲（电击）终端

> 逻辑 ID `DIANJI`。通过 WiFi 无线控制电脉冲输出，用于各种玩法的惩罚 / 反馈 / 记忆强化。

## 产品特性

- 无线控制（WiFi / BLE）
- 电压、延时、电击触发可调
- 默认 safe 模式，电压不高于 36V
- 开源 / DIY 组件，可编程

## 设备参数

| 项目 | 说明 |
| :--- | :--- |
| 逻辑 ID | DIANJI |
| 功能 | 电脉冲输出 |
| 控制属性 | voltage / delay / shock / safe |
| 电压范围 | safe 模式 ≤36V；关闭 safe 后最大 80V |
| 通信 | WiFi (2.4G) / BLE |

## 注意事项

1. 设备默认 safe 模式，电压不高于 36V。如需提升，请将 `safe` 属性设为 0，此时最大 80V，**此模式下请自行注意安全，出现问题后果自负**。
2. 请将电极插口插到底，否则没有输出。
3. 禁止在心脏、头部、躯干等核心部位使用，或让电流流经以上部位。
