# First-Time Use

:::info
Before solo play, read the [Safety Notes](/docs/player/solo-safety): playing alone requires a way out that does not depend on the device.
:::

First-time setup is just three steps.

## 1. Download the client

Install the [Android client](/docs/player/new-phone-client) on a phone, or the [Windows client](/docs/player/new-phone-client#pc) on a PC. For iPhone and HarmonyOS see the [iOS client](/docs/player/new-phone-client#ios) and [HarmonyOS client](/docs/player/new-phone-client#鸿蒙客户端).

## 2. Connect a device

For daily phone use, direct Bluetooth is enough: power on the device (blue light blinking), open the client, and tap "Add device". If you're using a PC or need WiFi, see [Choosing a connection method](/docs/start/connect) first.

## 3. Pick a play and start

Open the [play overview](/docs/player), pick a play, finish device mapping and parameters per the tutorial, and start.
