# Button Start (Solo Self-Restraint)

"Button start" is a start mode designed for solo play: you can **lock yourself first, then press the button on the lock to start the game** — nobody else needs to tap Start.

> Read the [Safety Notes](/docs/player/solo-safety) before solo play, and make sure you have a way out that does not depend on the device.

The flow is the same on phone and PC; only the entry differs:

## On the phone

1. Open the game you want, and finish device mapping and parameters.
2. At the bottom of the config page, tap **"Button start"**.
3. In "Choose a button trigger", pick an **online device that has a button** (such as the auto lock).
4. Tap **"Press once to test"**, then actually press the button on the lock. **"Button received"** means the test passed.
5. Tap **"Confirm"** to enter the "about to start" waiting page.
6. The game has not started yet. **Press the button on the lock once** and the game starts for real.

## On the computer

1. Open the game you want, and finish device mapping and parameters.
2. At the bottom of the config page, **next to the "Start" button**, click **"Start from device button"**.
3. In "Choose a button trigger", pick an **online device that has a button** (such as the auto lock).
4. Tap **"Test once"**, then actually press the button on the lock. **"Button received"** means the test passed.
5. Tap **"Confirm"** to enter the run page's "about to start" waiting state.
6. The game has not started yet. **Press the button on the lock once** and the game starts for real.

> Both waiting pages offer "Cancel" and "Force start": cancel returns you without playing; if you can't wait for the button, force-start begins immediately.
>
> You can only confirm into the waiting page after the button test passes — this prevents locking yourself up only to find the button does nothing and the game can't start.
