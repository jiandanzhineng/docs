# Tiptoe Penalty v2

A motion training game: the tiptoe standing challenge.

### V1.4.0 changes

1. **TD01 added:** after a set time with no shock, it starts and the intensity climbs, so a long clean stretch is not idle.
2. **Start from the ZIDONGSUO button:** for solo play. In manual-start mode, a button press starts the game.
3. **ZIDONGSUO and TD01 are optional:** the game runs with only a shock device and a QTZ sensor.

## Preparation

### 1. Devices

The game can connect four devices:

+ **Auto lock:** locks at start so you do not quit early (optional)
+ **Shock device:** immediate feedback
+ **QTZ sensor:** two buttons under the heel, watching whether the heel presses down
+ **TD01:** optional. After a set time with no shock, intensity climbs and makes tiptoe harder.

### 2. Parameters

+ **Duration:** 1–360 minutes
+ **Shock intensity:** 10–100
+ **Progressive mode:** more violations, stronger penalty
+ **Safety limit:** whether to allow voltage above the 30 V safety limit
+ **Manual start:** wait for a press on the auto_lock before the timer starts
+ **TD01 delay:** 1–60 seconds with no shock before TD01 starts
+ **TD01 step:** intensity added every 5 seconds (1–100)

## Play

### Core rule

Stay on tiptoe. The heel must not touch the ground.

#### 1. Start

+ A connected auto lock locks. You cannot quit early.
+ In manual-start mode, press the auto_lock button to start the timer.
+ Hold tiptoe. QTZ watches the heel.

#### 2. Monitoring

+ Two button points: button0 and button1
+ Pressing either button with the heel is a violation
+ A shock starts immediately
+ The shock stops only when both buttons are released

#### 3. Penalty

+ **Immediate:** shock starts the moment a button is pressed
+ **Progressive:** more violations raise shock intensity
+ **Continuous:** shock continues while a button is down, until the heel is fully up
+ **TD01:** after the set time with no shock, TD01 starts and intensity rises every 5 seconds

#### 4. TD01

+ **Delayed start:** starts after the set seconds with no shock
+ **Rising intensity:** adds the set amount every 5 seconds
+ **Max intensity:** 0–255, not limited by the safety cap
+ **Auto stop:** a shock stops it and resets the timer

#### 5. End

+ When the set time is reached, a connected lock unlocks
+ The report shows violation count, shock count, and related stats

## What it tests

+ **Endurance:** holding tiptoe works the calves
+ **Will:** you still have to hold the posture when you are tired
+ **Precision:** a small heel drop is detected
+ **Focus:** stay calm under the shock
+ **Two pressures:** avoid the shock, and deal with TD01

## Result bands

Finish the set time. Fewer violations is a better result:

+ **Perfect:** 0 violations
+ **Excellent:** 1–2 violations
+ **Good:** 3–5 violations
+ **Needs work:** more than 5 violations

## Safety

+ Do not use this if you have a heart condition, epilepsy, or a similar condition
+ Start with a lower intensity and a shorter time
+ Stop immediately if you feel unwell
+ Adults 18 and older only
+ Set shock intensity carefully. Too high can cause injury. You accept that risk
+ If you allow voltage above the safety limit, you accept that risk
+ Keep the space safe. Having someone nearby is recommended

## Extra features

### Manual start

+ After loading, a waiting screen is shown
+ The auto lock locks first
+ Press the auto_lock button to start the timer
+ Useful when you need time to get ready

### Live shock

+ Any button down starts a continuous shock
+ All buttons up stops the shock immediately

### TD01

+ Optional extra challenge
+ Raises difficulty during a clean stretch
+ Intensity climbs
+ Intensity is controlled separately
