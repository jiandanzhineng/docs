# Simple Smart Pulse (Electric Shock) Terminal

> Logic ID `DIANJI`. It controls electric-pulse output over Wi-Fi for penalty, feedback, and memory play.

## Features

- Wireless control (Wi-Fi / BLE)
- Voltage, delay, and shock trigger are adjustable
- Safe mode by default, voltage not above 36 V
- Open-source / DIY module, programmable

## Specifications

| Item | Detail |
| :--- | :--- |
| Logic ID | DIANJI |
| Function | Electric pulse output |
| Control fields | voltage / delay / shock / safe |
| Voltage | Safe mode ≤ 36 V; up to 80 V if safe mode is off |
| Radio | Wi-Fi (2.4G) / BLE |

## Notes

1. Safe mode is on by default, so voltage stays at or below 36 V. To go higher, set `safe` to 0. The maximum is then 80 V. **In that mode you are responsible for safety.**
2. Push the electrode plug in all the way, or there is no output.
3. Do not use it on the heart, head, or torso, and do not let current pass through those areas.
