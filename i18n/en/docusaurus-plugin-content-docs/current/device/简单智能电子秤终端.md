# Simple Smart Electronic Scale (DZC01)

> Logic ID `DZC01`. A smart scale terminal built on an HX711 load cell. It reports weight live and has an OLED that can show custom text.

## Features

- High-resolution weighing (HX711)
- Live weight reports
- OLED with two custom text lines
- Display on/off, contrast, and display mode
- Button trigger

## Specifications

| Item | Detail |
| :--- | :--- |

| Radio | Wi-Fi (2.4G) / BLE |
