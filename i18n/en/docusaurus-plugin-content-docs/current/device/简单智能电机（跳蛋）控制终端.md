# Simple Smart Motor (Vibrator) Control Terminal

> Logic ID `TD01`. It controls vibrator intensity over Wi-Fi and can join several plays.

## Features

- Wireless control (Wi-Fi / BLE)
- Vibration intensity 0–255
- Accepts a common USB vibrator
- Large battery
- Open source, with a Python API

## Specifications

| Item | Detail |
| :--- | :--- |
| Logic ID | TD01 |
| Function | Motor / vibrator control |
| Control field | power (0–255) |
| Power | Built-in battery + USB-C charging |
| Radio | Wi-Fi (2.4G) / BLE |
