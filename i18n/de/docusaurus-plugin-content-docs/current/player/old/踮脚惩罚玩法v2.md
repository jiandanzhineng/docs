# Zehenspitzen-Bestrafungsspielweise v2

Hightech-Körpergefühls-Selbst­disziplin-Trainingsspiel — Stehen-auf-den-Zehenspitzen-Challenge

### Neuerungen in V1.4.0:
1. **Neues TD01-Gerät**: Damit es auf Dauer nicht langweilig wird, startet es, wenn eine gewisse Zeit kein Elektroschock ausgelöst wurde, und steigert die Stärke schrittweise.
2. **Neues Spielstart per zidongsuo-Taste**: Für Solo-Bedienung; bei aktiviertem manuellem Startmodus kann das Spiel per Tastendruck gestartet werden.
3. **zidongsuo und TD01 sind optionale Geräte**: Das Spiel funktioniert auch ohne beide — nur Elektroschock-Gerät und QTZ-Sensor sind nötig.

## 🎮 Spielweise im Detail
### 📋 Spielvorbereitung
#### 1. Gerätekonfiguration
Das System verbindet automatisch vier Kerngeräte:

+ 🔒 **Automatisches Schloss**: Verriegelt zu Spielbeginn und verhindert vorzeitiges Aufhören (optionales Gerät)
+ ⚡ **Elektroschock-Gerät**: Sofortige Feedback-Bestrafung
+ 📡 **QTZ-Lasersensor**: Überwacht über zwei Taster, ob die Ferse aufgesetzt wird (unter der Ferse platzieren)
+ 🎮 **TD01-Gerät**: Optionales Zusatzgerät, das nach einer gewissen Zeit ohne Elektroschock startet, die Stärke schrittweise erhöht und den Zehenspitzenstand stört.

#### 2. Parametereinstellung
Der Schwierigkeitsgrad ist frei einstellbar:

+ **Spieldauer**: 1–360 Minuten einstellbar
+ **Elektroschock-Stärke**: Stufen 10–100
+ **Progressiver Modus**: Je mehr Verstöße, desto härter die Strafe
+ **Sicherheitsgrenze**: Wählbar, ob das 30-V-Sicherheitslimit überschritten werden darf
+ **Manueller Start**: Wählbar — das Spiel beginnt erst nach Tastendruck am auto_lock-Gerät
+ **TD01-Verzögerung**: 1–60 Sekunden einstellbar; wie lange ohne Elektroschock bis zum TD01-Start
+ **TD01-Stärkezuwachs**: Stärkeerhöhung alle 5 Sekunden (1–100)

## 🎯 Konkrete Spielweise
### Kernregel
Halte den Stand auf den Zehenspitzen — die Fersen dürfen auf keinen Fall den Boden berühren!

#### 1. Spielstart
+ Das System verriegelt automatisch (falls ein automatisches Schloss vorhanden ist), ein vorzeitiger Ausstieg ist nicht möglich.
+ Bei aktiviertem manuellem Startmodus muss die Zeitmessung per Tastendruck am auto_lock-Gerät gestartet werden.
+ Die Zeitmessung beginnt — die Zehenspitzenhaltung muss gehalten werden.
+ Der QTZ-Sensor überwacht die Fersenposition in Echtzeit.

#### 2. Überwachungsmechanismus
+ Der Sensor besitzt zwei Taster-Erkennungspunkte (button0 und button1).
+ Sobald die Ferse einen der Taster niederdrückt = Verstoß.
+ Das System löst sofort eine Elektroschock-Strafe aus.
+ Der Elektroschock stoppt erst, wenn beide Taster wieder frei sind.

#### 3. Bestrafungssystem
+ 🔴 **Sofortbestrafung**: Der Elektroschock beginnt in dem Moment, in dem die Ferse einen Taster drückt.
+ 📈 **Progressive Stärke**: Mit jedem Verstoß steigt die Elektroschock-Stärke automatisch.
+ ⏱️ **Dauerbestrafung**: Solange ein Taster gedrückt bleibt, geht der Elektroschock weiter, bis die Ferse komplett angehoben ist.
+ 🎮 **TD01-Zusatzbestrafung**: Nach der eingestellten Zeit ohne Elektroschock startet das TD01-Gerät, dessen Stärke alle 5 Sekunden steigt.

#### 4. TD01-Gerätemechanik
+ **Verzögerter Start**: Startet automatisch nach der eingestellten Sekundenzahl ohne Elektroschock.
+ **Stärkeanstieg**: Erhöht alle 5 Sekunden automatisch um den eingestellten Wert.
+ **Maximale Stärke**: Bereich 0–255, vom Sicherheitslimit unberührt.
+ **Automatischer Stopp**: Stoppt und wird zurückgesetzt, sobald ein Elektroschock ausgelöst wird.

#### 5. Spielende
+ Wer die eingestellte Zeit durchhält, wird automatisch entriegelt.
+ Das System zeigt einen vollständigen Leistungsbericht.
+ Statistik zu Verstößen, Elektroschock-Anzahl usw.

## 💪 Herausforderungen
+ **Körperliche Challenge**: Langer Zehenspitzenstand testet die Ausdauer der Beinmuskulatur.
+ **Willensprobe**: Trotz Ermüdung muss die korrekte Haltung gehalten werden.
+ **Präzise Kontrolle**: Jede noch so kleine Fersensenkung wird erkannt.
+ **Psychologisches Spiel**: Unter Elektroschock-Androhung ruhig und konzentriert bleiben.
+ **Doppelter Druck**: Elektroschock vermeiden und gleichzeitig die TD01-Störung ertragen.

## 🏆 Siegbedingung
Die eingestellte Zeit erfolgreich durchhalten — je weniger Verstöße, desto besser:

+ 🌟 **Perfekt**: 0 Verstöße
+ ⭐ **Ausgezeichnet**: 1–2 Verstöße
+ 👍 **Gut**: 3–5 Verstöße
+ 😅 **Verbesserungswürdig**: mehr als 5 Verstöße

## ⚠️ Sicherheitshinweise
+ Nur bei guter Gesundheit verwenden — nicht bei Herzkrankheiten, Epilepsie usw.
+ Mit niedriger Stärke und kurzer Dauer beginnen.
+ Bei Unwohlsein während des Spiels sofort abbrechen.
+ Nur für Erwachsene über 18 Jahre.
+ Elektroschock-Stärke vorsichtig einstellen — zu hohe Werte können Verletzungen verursachen; das Risiko trägt der Nutzer selbst.
+ Bei aktivierter Funktion zum Überschreiten des Sicherheitslimits handelst du auf eigenes Risiko.
+ Für eine sichere Spielumgebung sorgen; eine Aufsichtsperson wird empfohlen.

## 🔧 Besondere Funktionen
### Manueller Startmodus
+ Nach dem Laden zeigt das Spiel eine Warteanzeige.
+ Das automatische Schloss verriegelt zuerst.
+ Die Spielzeit startet erst per Tastendruck am auto_lock-Gerät.
+ Ideal für Situationen, in denen Vorbereitungszeit nötig ist.

### Echtzeit-Elektroschock-Mechanik
+ Sobald irgendein Taster gedrückt wird, beginnt sofort der Dauer-Elektroschock.
+ Sobald alle Taster frei sind, stoppt der Elektroschock sofort.
+ Der direktest mögliche Feedback-Mechanismus.

### TD01-Verstärkersystem
+ Optionales Zusatz-Challenge-Gerät.
+ Erhöht die Schwierigkeit bei guter Leistung.
+ Stärke steigt schrittweise und baut Spannung auf.
+ Unabhängige Stärkesteuerung.
