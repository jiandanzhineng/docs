# Erste Verwendung

:::info
Lies vor dem Solo-Spiel bitte die [Sicherheitshinweise](/docs/player/solo-safety): Für Solo-Spiel ist ein vom Gerät unabhängiger Befreiungsweg Pflicht.
:::

Bei der ersten Verwendung einfach die folgenden drei Schritte abarbeiten.

## 1. Client herunterladen und installieren

Auf dem Handy den [Android-Client](/docs/player/new-phone-client) installieren, auf dem PC den [Windows-Client](/docs/player/new-phone-client#pc); für iPhone und HarmonyOS siehe [iOS-Client](/docs/player/new-phone-client#ios) bzw. [HarmonyOS-Client](/docs/player/new-phone-client#鸿蒙客户端).

## 2. Gerät verbinden

Am Handy im Alltag die Bluetooth-Direktverbindung nutzen: Gerät einschalten — blaue LED blinkt — im Client auf „Gerät hinzufügen“ tippen. Für PC-Nutzung oder wenn WLAN nötig ist, zuerst [Welche Verbindungsart wählen](/docs/start/connect) lesen.

## 3. Spielweise wählen und starten

Öffne die [Spielweisen-Übersicht](/docs/player), wähle eine Spielweise, schließe nach Tutorial Gerätezuordnung und Parameterkonfiguration ab — dann kann es losgehen.
