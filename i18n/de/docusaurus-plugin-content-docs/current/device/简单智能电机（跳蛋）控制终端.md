# Einfaches intelligentes Motor-(Vibrator-)Steuerungsterminal

> Logische ID `TD01`. Steuert die Vibrationsstärke eines Motors (Vibro-Eis) drahtlos per WiFi; lässt sich in viele Spielweisen einbinden.

## Produktmerkmale

- Drahtlose Steuerung (WiFi / BLE)
- Vibrationsstärke in 0–255 Stufen regelbar
- Unterstützt den Anschluss normaler USB-Vibro-Eier
- Akku mit großer Kapazität
- Open Source, mit Python-Schnittstelle für eigene Entwicklung

## Geräteparameter

| Punkt | Beschreibung |
| :--- | :--- |
| Logische ID | TD01 |
| Funktion | Motor- / Vibratorsteuerung |
| Steuerattribut | power (0~255) |
| Stromversorgung | Integrierter Akku großer Kapazität + Type-C-Laden |
| Kommunikation | WiFi (2,4G) / BLE |
