# Einfaches intelligentes Waagen-Terminal (DZC01)

> Logische ID `DZC01`. Intelligentes Waagen-Terminal auf Basis des HX711-Wägesensors; meldet das Gewicht in Echtzeit und besitzt ein OLED-Display, auf das benutzerdefinierter Text gesendet werden kann.

## Produktmerkmale

- Hochpräzises Wiegen (HX711-Sensor)
- Echtzeit-Gewichtsmeldung
- OLED-Display mit zwei frei definierbaren Textzeilen
- Display-Ein/Aus, Kontrast und Anzeigemodus einstellbar
- Tasten-Auslösung

## Geräteparameter

| Punkt | Beschreibung |
| :--- | :--- |
| Logische ID | DZC01 |
| Funktion | Waage (HX711 + OLED) |
| Kommunikation | WiFi (2,4G) / BLE |
| Firmware-Fähigkeiten | weight / display_mode / display_on / display_contrast / line1_text / line2_text / button2 |
