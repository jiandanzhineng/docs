# Steuerungsterminal für oszillierenden Motor mit Intensitätsregelung (Fucking-Machine-Controller)

> Auch bekannt als „Fucking-Machine-Controller“, logische ID `PJ01`. Steuert die Stärke eines oszillierenden Motors (Fucking Machine) drahtlos per WiFi und lässt sich als Stimulationsausgang in Edging-Spielweisen einbinden.

## Produktmerkmale

- Drahtlose Steuerung (WiFi / BLE)
- PWM-Motordrehzahlregelung, Stärke 0–255 Stufen
- Externe Stromversorgung (hohe Leistung, kein eingebauter Akku)
- Unterstützt die Kopplung mit Edging-Spielweisen

## Geräteparameter

| Punkt | Beschreibung |
| :--- | :--- |
| Logische ID | PJ01 |
| Funktion | PWM-Motorsteuerung (oszillierend / Fucking Machine) |
| Steuerattribut | power (0~255) |
| Stromversorgung | Externe Stromversorgung (kein Akku) |
| Kommunikation | WiFi (2,4G) / BLE |
