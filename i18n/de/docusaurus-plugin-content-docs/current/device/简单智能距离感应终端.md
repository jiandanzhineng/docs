# Einfaches intelligentes Abstandssensor-Terminal

> Logische ID `QTZ`. Erkennt Körperhöhe / Bewegungen über einen Abstandssensor — für Spielweisen mit Bewegungserkennung wie Liegestütze oder Zehenspitzen.

![Abstandssensor-Terminal ##w30%##](./img/Qu8mhshxEPagKgZC/1750854320916-7f1d258e-fcde-49d3-b249-d6202d7061cc-516028.png)

## Produktmerkmale

- Echtzeit-Abstandsmeldung (Millimeter-Genauigkeit)
- Auslösung über Doppeltaster-Fußplatte
- Erkennung von Abstandszonen (niedriges / hohes Band)
- Type-C-Laden

## Geräteparameter

| Punkt | Beschreibung |
| :--- | :--- |
| Logische ID | QTZ |
| Funktion | Abstands- / Höhenerkennung |
| Steuerattribute | distance / low_band / high_band / button0 / button1 |
| Stromversorgung | Integrierter Akku + Type-C-Laden |
| Kommunikation | WiFi (2,4G) / BLE |
