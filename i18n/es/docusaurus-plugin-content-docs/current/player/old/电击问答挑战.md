# Desafío de Preguntas y Respuestas con Descarga Eléctrica

## Introducción del Juego
El juego de preguntas y respuestas es un modo de juego de trivia que permite importar preguntas externas. Los jugadores deben responder preguntas dentro de un tiempo límite. Una respuesta correcta avanza a la siguiente pregunta, mientras que una respuesta incorrecta resulta en un castigo de descarga eléctrica y la pregunta se vuelve a colocar al final para responderla más tarde.

## Características del Juego
+ 📚 **Banco de preguntas personalizable**: Admite importar archivos de preguntas en formato JSON externo
+ ⚡ **Castigo con descarga eléctrica**: Las respuestas incorrectas activan un dispositivo de descarga para el castigo
+ ⏰ **Límite de tiempo**: Cada pregunta tiene un límite de tiempo para responder, si se excede se considera incorrecta
+ 🎮 **Múltiples métodos de control**: Admite control por clic de ratón y por dispositivo de teclas QTZ
+ 🔒 **Inicio manual**: Se puede elegir el modo de inicio manual, activando el juego mediante el dispositivo de bloqueo automático

## Configuración de Parámetros del Juego
### Configuración de Preguntas
+ **Ruta del archivo de preguntas**: Especifica la ruta del archivo JSON que contiene las preguntas
    - Por defecto: `<OUTTER_GAME>/QA-game/女仆行为规范考核题库.json`
    - Admite la marca `<OUTTER_GAME>` que apunta a la carpeta outter-game después del empaquetado

### Configuración del Castigo
+ **Intensidad de la descarga**: Intensidad de la descarga eléctrica al responder incorrectamente (10-100)
+ **Duración de la descarga**: Duración de la descarga eléctrica (1-10 segundos)

### Configuración del Tiempo
+ **Límite de tiempo por pregunta**: Límite de tiempo para responder cada pregunta (10-300 segundos, 0 significa sin límite)

### Configuración de Inicio
+ **Inicio manual**: Cuando está habilitado, se requiere presionar una tecla en el dispositivo de bloqueo automático para comenzar el juego

## Formato del Archivo de Preguntas
El archivo de preguntas debe estar en formato JSON y tener la siguiente estructura:

```json
{
  "questions": [
    {
      "question": "Contenido de la pregunta",
      "options": ["Opción A", "Opción B", "Opción C", "Opción D"],
      "correct": 0,
      "explanation": "Explicación de la respuesta (opcional)"
    }
  ]
}
```

### Descripción de los Campos
+ `question`: Texto de la pregunta
+ `options`: Arreglo de opciones
+ `correct`: Índice de la respuesta correcta (comienza desde 0)
+ `explanation`: Explicación de la respuesta (opcional)

## Flujo del Juego
1. **Preparación del juego**
    - Cargar el archivo de preguntas
    - Verificar el estado de conexión del equipo
    - Inicializar los parámetros del juego
2. **Inicio del juego**
    - Modo inicio manual: Esperar la señal de la tecla del dispositivo de bloqueo automático
    - Modo inicio automático: Comenzar inmediatamente la primera pregunta
3. **Proceso de respuesta**
    - Mostrar la pregunta y las opciones
    - Bloquear el dispositivo de bloqueo automático (para evitar salir a mitad del juego)
    - Iniciar cuenta regresiva
    - Esperar a que el jugador seleccione una respuesta
4. **Evaluación de la respuesta**
    - **Respuesta correcta**: Mostrar confirmación de acierto y pasar a la siguiente pregunta
    - **Respuesta incorrecta o tiempo excedido**: Activar castigo de descarga eléctrica y colocar la pregunta al final de la cola para responderla nuevamente
5. **Fin del juego**
    - El juego termina cuando se responden correctamente todas las preguntas
    - Desbloquear el dispositivo de bloqueo automático
    - Mostrar estadísticas del juego

## Métodos de Control
### Control con Ratón
+ Hacer clic en el botón de opción para seleccionar la respuesta

### Control con Teclas QTZ
+ **Tecla 0**: Cambiar a la opción superior
+ **Tecla 1**: Cambiar a la opción inferior / Confirmar selección
+ La opción seleccionada se muestra resaltada

## Notas Importantes
1. Asegúrese de que el dispositivo de descarga eléctrica esté correctamente conectado y configurado. Ajuste usted mismo la intensidad del voltaje. Cualquier lesión por descarga eléctrica debida a una intensidad excesiva es su responsabilidad.
2. El dispositivo de bloqueo automático, debido a factores como condiciones de red, puede mostrar inestabilidad. Asegúrese de tener herramientas para liberarse en caso de emergencia.
