# Primer uso

:::info
Antes de jugar solo, lee primero los [avisos de seguridad](/docs/player/solo-safety): para jugar solo es obligatorio tener un medio de liberación independiente del dispositivo.
:::

En el primer uso basta seguir estos tres pasos.

## 1. Descargar e instalar el cliente

En el móvil instala el [cliente Android](/docs/player/new-phone-client); en el ordenador instala el [cliente Windows](/docs/player/new-phone-client#pc). Para iPhone y HarmonyOS consulta respectivamente el [cliente iOS](/docs/player/new-phone-client#ios) y el [cliente HarmonyOS](/docs/player/new-phone-client#鸿蒙客户端).

## 2. Conectar el dispositivo

En el móvil se usa a diario la conexión directa por Bluetooth: enciende el dispositivo, luz azul parpadeando, abre el cliente y pulsa «Añadir dispositivo». Para usar el ordenador o cuando necesites WiFi, lee primero [cómo elegir la forma de conexión](/docs/start/connect).

## 3. Elegir un juego y empezar

Abre la [visión general de juegos](/docs/player), elige uno, completa el mapeo de dispositivos y la configuración de parámetros según el tutorial y ya puedes empezar.
