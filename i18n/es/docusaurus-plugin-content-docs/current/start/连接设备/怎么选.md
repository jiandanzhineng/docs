# Cómo elegir la forma de conexión

El dispositivo tiene dos formas de conexión, Bluetooth y WiFi, y solo se puede usar una: tras configurar la red o conectarse a un punto de acceso, el dispositivo apaga automáticamente el Bluetooth; para volver a la conexión directa por Bluetooth hay que poner el dispositivo en modo BLE.

| Forma | Para quién | Requisito previo | Nota |
| --- | --- | --- | --- |
| [Conexión directa por Bluetooth (móvil)](/docs/start/connect/ble) | Juego diario con el móvil | Dispositivo con luz azul parpadeando, Bluetooth del móvil activado | Tras configurar la red o conectarse a un punto de acceso, el dispositivo apaga el Bluetooth; hay que volver a modo BLE |
| [Punto de acceso del PC](/docs/start/connect/hotspot) | Jugar con el cliente de PC | El PC puede abrir un punto de acceso 2.4G con nombre `easysmart` y contraseña `11111111` | El cliente de PC solo puede controlar los dispositivos propios por WiFi / red local; el Bluetooth del PC solo sirve para [dispositivos de otras marcas](/docs/start/connect/brand-devices) (como DG-LAB) |
| [Configurar en el WiFi de casa](/docs/start/connect/pc-home-wifi) (sirve móvil o PC) | El PC no puede abrir punto de acceso, control remoto desde el móvil, actualización de firmware, varios dispositivos en línea | Hay WiFi 2.4G en casa y el router admite mDNS | La configuración de red solo admite WiFi 2.4G; tras configurarla el dispositivo apaga automáticamente el Bluetooth |
| Punto de acceso del móvil (modo A del servicio de red local de Android) | Sin router, con móvil Android | Móvil Android, punto de acceso con nombre `easysmart` y contraseña `11111111` | Solo Android; el dispositivo se conecta automáticamente al Broker de la puerta de enlace. El iPhone no puede usar puntos de acceso con nombre fijo, solo sirve la configuración por router |

El dispositivo se conecta por defecto automáticamente al WiFi de nombre `easysmart` y contraseña `11111111`; si no quieres configurar la red puedes usar directamente este WiFi por defecto.

## Recomendación

- **Juego diario con el móvil**: usa la [conexión directa por Bluetooth](/docs/start/connect/ble), enciende el dispositivo y juega.
- **Jugar con el PC**: haz que el PC abra un [punto de acceso 2.4G](/docs/start/connect/hotspot); si no puedes abrir punto de acceso, [configura en el WiFi de casa](/docs/start/connect/pc-home-wifi).
- **Para control remoto desde el móvil, actualización de firmware y varios dispositivos en línea**: usa la configuración de red o el «servicio de red local» del móvil, para que el dispositivo se conecte al WiFi.
