# Punto de acceso del PC (conectar dispositivos al PC)

El cliente de PC solo puede controlar los dispositivos propios por WiFi / red local; no puede conectarse directamente por Bluetooth como el móvil. El Bluetooth del PC solo sirve para [dispositivos de otras marcas](/docs/start/connect/brand-devices) (DG-LAB, etc.). La forma más sencilla es abrir un punto de acceso en el PC: el dispositivo se conectará automáticamente.

1. Activa el punto de acceso del PC con nombre de WiFi `easysmart`, contraseña `11111111` y la banda debe ser **2.4G**.
2. Si el dispositivo se conecta al WiFi pero no aparece en el cliente, desactiva el firewall del PC.
3. Enciende el dispositivo; unos 15~30 segundos después de arrancar se conectará automáticamente al PC.

## Nota

- Si el dispositivo ya estuvo conectado a un WiFi 5G, puede seguir en la banda 5G aunque configures 2.4G; en ese caso haz que el dispositivo se conecte una vez a un WiFi 2.4G (o por cable de red) y vuelve a intentarlo.
- El dispositivo se conecta por defecto automáticamente al WiFi de nombre `easysmart` y contraseña `11111111`; si no quieres configurar la red puedes usar directamente este WiFi por defecto.

Si no puedes abrir un punto de acceso en el PC, puedes [configurar el dispositivo en el WiFi de casa](/docs/start/connect/pc-home-wifi) y el PC se conectará por la red local.
