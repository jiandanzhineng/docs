> **Nota: la conexión BLE (Bluetooth) y la conexión WiFi del dispositivo son una u otra, no se pueden usar a la vez.** Tras configurar la red con éxito y conectarse al WiFi, el dispositivo apaga automáticamente el Bluetooth; si necesitas controlar el dispositivo con conexión directa por Bluetooth, hay que cambiar a modo BLE (en ese momento el WiFi se desconecta). Consulta las explicaciones en los documentos de configuración de red más abajo.
