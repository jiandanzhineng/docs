# Terminal de control de motor inteligente simple (vibrador)

> ID lógico `TD01`. Controla por WiFi de forma inalámbrica la intensidad de vibración del motor (vibrador); se puede integrar en múltiples juegos.

## Características del producto

- Control inalámbrico (WiFi / BLE)
- Intensidad de vibración regulable de 0 a 255
- Admite conexión de vibradores USB normales
- Batería de gran capacidad
- Código abierto, admite desarrollo secundario en Python

## Parámetros del dispositivo

| Elemento | Descripción |
| :--- | :--- |
| ID lógico | TD01 |
| Función | Control de motor / vibrador |
| Atributos de control | power (0~255) |
| Alimentación | Batería integrada de gran capacidad + carga Type-C |
| Comunicación | WiFi (2.4G) / BLE |
