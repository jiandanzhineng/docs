# Terminal de pulso (descarga) inteligente simple

> ID lógico `DIANJI`. Controla la salida de pulsos eléctricos de forma inalámbrica por WiFi; se usa para castigo / retroalimentación / refuerzo de memoria en diversos juegos.

## Características del producto

- Control inalámbrico (WiFi / BLE)
- Voltaje, retardo y disparo de descarga ajustables
- Modo safe por defecto, voltaje no superior a 36V
- Componente de código abierto / DIY, programable

## Parámetros del dispositivo

| Elemento | Descripción |
| :--- | :--- |
| ID lógico | DIANJI |
| Función | Salida de pulsos eléctricos |
| Atributos de control | voltage / delay / shock / safe |
| Rango de voltaje | modo safe ≤36V; tras desactivar safe, máximo 80V |
| Comunicación | WiFi (2.4G) / BLE |

## Precauciones

1. El dispositivo está por defecto en modo safe, con voltaje no superior a 36V. Si necesitas subirlo, pon el atributo `safe` en 0; entonces el máximo es 80V. **En este modo ten cuidado con la seguridad; los problemas son responsabilidad tuya**.
2. Inserta la clavija del electrodo hasta el fondo; de lo contrario no habrá salida.
3. Prohibido usarlo en el corazón, la cabeza, el torso u otras zonas centrales, ni dejar que la corriente pase por esas zonas.
