# Terminal de báscula electrónica simple e inteligente (DZC01)

> ID lógico `DZC01`. Terminal de báscula electrónica inteligente basado en el sensor de peso HX711, que informa del peso en tiempo real y dispone de pantalla OLED con posibilidad de enviar texto personalizado.

## Características del producto

- Pesaje de alta precisión (sensor HX711)
- Informe de peso en tiempo real
- Pantalla OLED, admite dos líneas de texto personalizado
- Interruptor de pantalla, contraste y modo de visualización ajustables
- Activación por botón

## Parámetros del dispositivo

| Elemento | Descripción |
| :--- | :--- |
| ID lógico | DZC01 |
| Función | Báscula electrónica (HX711 + OLED) |
| Comunicación | WiFi (2.4G) / BLE |
| Capacidades del firmware | weight / display_mode / display_on / display_contrast / line1_text / line2_text / button2 |
