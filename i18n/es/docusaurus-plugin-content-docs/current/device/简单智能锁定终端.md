# Terminal de bloqueo inteligente simple

> ID lógico `ZIDONGSUO`. Controla el bloqueo / desbloqueo de forma inalámbrica por WiFi; se usa en juegos que requieren restricción forzada, como «no te vas hasta terminar».

![Terminal de bloqueo ##w30%##](./img/ZGvq049xBaouj3MU/1750851448187-f17fa36f-e863-4896-9329-9b00b6095a9b-531187.png)

## Características del producto

- Control inalámbrico de bloqueo / desbloqueo (WiFi / BLE)
- Mantener el botón pulsado 60 segundos fuerza el desbloqueo
- Desbloqueo automático cuando la batería baja del 20% (antiencierro)
- Programable, admite control por temporizador
- Carga Type-C

## Parámetros del dispositivo

| Elemento | Descripción |
| :--- | :--- |
| ID lógico | ZIDONGSUO |
| Función | Bloqueo automático |
| Atributos de control | open |
| Alimentación | Batería integrada + carga Type-C |
| Comunicación | WiFi (2.4G) / BLE |

## Precauciones

1. ¡Ten a mano herramientas de liberación durante el uso! Por problemas de red, el dispositivo no puede garantizar el desbloqueo.
2. Dirección del interruptor: alejándose del puerto de carga se enciende, en caso contrario se apaga
