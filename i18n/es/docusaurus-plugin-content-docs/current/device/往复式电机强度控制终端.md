# Terminal de control de intensidad de motor recíproco (controlador de máquina de impacto)

> Es el «controlador de máquina de impacto», ID lógico `PJ01`. Controla por WiFi de forma inalámbrica la intensidad del motor recíproco (máquina de impacto); se puede integrar en el juego de edging como salida de estimulación.

## Características del producto

- Control inalámbrico (WiFi / BLE)
- Regulación de velocidad del motor por PWM, intensidad de 0 a 255
- Alimentación por fuente externa (gran potencia, sin batería integrada)
- Admite integración con el juego de edging

## Parámetros del dispositivo

| Elemento | Descripción |
| :--- | :--- |
| ID lógico | PJ01 |
| Función | Control de motor PWM (recíproco / máquina de impacto) |
| Atributos de control | power (0~255) |
| Alimentación | Fuente externa (sin batería) |
| Comunicación | WiFi (2.4G) / BLE |
