# シンプルスマートモーター（バイブレーター）制御端末

> ロジックID `TD01`。WiFi 無線制御でモーター（バイブレーター）の振動強度を調整し、さまざまなプレイに接続できます。

## 製品特徴

- 無線制御（WiFi / BLE）
- 振動強度 0~255 レベル調整
- 通常の USB バイブレーター接続に対応
- 大容量バッテリー
- オープンソース、Python 二次開発に対応

## デバイスパラメータ

| 項目 | 説明 |
| :--- | :--- |
| ロジック ID | TD01 |
| 機能 | モーター / バイブレーター制御 |
| 制御属性 | power（0~255） |
| 給電 | 内蔵大容量バッテリー + Type-C 充電 |
| 通信 | WiFi (2.4G) / BLE |
