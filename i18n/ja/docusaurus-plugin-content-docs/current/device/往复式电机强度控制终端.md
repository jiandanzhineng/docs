# 往復式モーター強度制御端末（バイブレーターマシンコントローラー）

> 「バイブレーターマシンコントローラー」とも呼ばれ、ロジック ID `PJ01`。WiFi 無線制御で往復式モーター（バイブレーターマシン）の強度を調整し、寸止めプレイの刺激出力として接続できます。

## 製品特徴

- 無線制御（WiFi / BLE）
- PWM モーター速度調整、強度 0~255 レベル
- 外部電源供給（高出力、バッテリーなし）
- 寸止めプレイとの連携に対応

## デバイスパラメータ

| 項目 | 説明 |
| :--- | :--- |
| ロジック ID | PJ01 |
| 機能 | PWM モーター制御（往復式 / バイブレーターマシン） |
| 制御属性 | power（0~255） |
| 給電 | 外部電源（バッテリーなし） |
| 通信 | WiFi (2.4G) / BLE |
