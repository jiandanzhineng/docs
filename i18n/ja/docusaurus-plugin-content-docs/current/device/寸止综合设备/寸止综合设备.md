# 寸止め総合デバイス（第2世代）

> 制御不能寸前の極致のコントロール —— エア漏れとさよならし、無限の連続プレイ、多様なモードに没入。スマホひとつで即プレイ。

寸止め総合デバイスは「硅基之下」のフラッグシップホストで、**気圧センサー、振動刺激、電気パルス**の3-in-1を1台のホストに集約。スマホ / PCクライアントと連携し、単体で寸止め、肛門引き締め、つま先立ちなど多彩なプレイを楽しめます。

## 主なセールスポイント

- **精密なトリガー**：高精度圧力測定、100ms の高速応答
- **安心の連続稼働**：2000mAh 大容量バッテリー、専用定電圧チップで、電量が低くても刺激は減衰なし
- **負担のない装着感**：29mm 極細アナルプラグ + 太もも固定の目立たないデザイン
- **1台で多様な遊び方**：寸止め / 肛門引き締め / つま先立ち。複数デバイスの連携もサポート

## バージョンとアクセサリー

### バージョン紹介 {#版本介绍}

【フル版】寸止めデバイス（気圧+振動+電撃）+ 男性用シングルアイテム + つま先立ちセンサー

【寸止め版】寸止めデバイス（気圧+振動+電撃）+ 男性用シングルアイテム

【OSR6版】寸止めデバイス（気圧+振動+電撃）

アクセサリー：つま先立ちセンサー、アナルプラグ圧力センサー。女性用には別途バイブレーターマシン + [バイブレーターマシンコントローラー](/docs/device/reciprocating-motor)が必要です。

**パッケージに充電ケーブルは含まれません**。ホストは一般的なスマホ充電ケーブル（Type-C）で充電できますので、別途購入の必要はありません。

### 購入ガイド {#导购}

1. 寸止め+電撃プレイ -> 寸止め版
2. つま先立ちプレイも試したい -> フル版
3. 遊び終わるまで帰れない（ロック機能追加） -> 自動ロックを別途購入
4. OSRデバイスをお持ちの方 -> OSR6版
5. 女性の方でバイブレーターマシンを使いたい方 -> バイブレーターマシンコントローラーを別途購入
6. その他ご不明な点は淘宝カスタマーサービスまたはグループにお問い合わせください～

### 用語解説 {#名词解释}

寸止めデバイス = 寸止めホスト + 圧力センサーアナルプラグ + 通常サイズのバイブレーター + 電撃パッド

ロック = 自動ロック

男性用シングルアイテム = 小型バイブレーター + ペニスカバー（下図参照）

女性用シングルアイテム = バイブレーターマシン + バイブレーターマシンコントローラー
