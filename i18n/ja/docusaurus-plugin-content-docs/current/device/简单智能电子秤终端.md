# シンプルスマート電子はかり端末（DZC01）

> ロジック ID `DZC01`。HX711 計量センサーベースのスマート電子はかり端末。重量をリアルタイムで報告し、OLED ディスプレイを搭載、カスタムテキストの送信が可能です。

## 製品の特徴

- 高精度計量（HX711 センサー）
- 重量のリアルタイム報告
- OLED ディスプレイ、カスタム2行テキスト対応
- 表示オン/オフ、コントラスト、表示モード調整可
- ボタントリガー
