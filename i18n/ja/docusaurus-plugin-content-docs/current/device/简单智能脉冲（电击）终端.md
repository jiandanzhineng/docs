# シンプルスマートパルス（電撃）端末

> ロジック ID `DIANJI`。WiFi 無線制御で電気パルスを出力し、各種プレイのペナルティ / フィードバック / 記憶強化に使用します。

## 製品特徴

- 無線制御（WiFi / BLE）
- 電圧、遅延、電撃トリガー調整可
- デフォルト safe モード、電圧 36V 以下
- オープンソース / DIY キット、プログラム可能

## デバイスパラメータ

| 項目 | 説明 |
| :--- | :--- |
| ロジック ID | DIANJI |
| 機能 | 電気パルス出力 |
| 制御属性 | voltage / delay / shock / safe |
| 電圧範囲 | safe モード ≤36V；safe 解除後最大 80V |
| 通信 | WiFi (2.4G) / BLE |

## 注意事項

1. デバイスはデフォルトで safe モードになっており、電圧は 36V を超えません。これを超えたい場合は `safe` 属性を 0 に設定してください。この場合、最大 80V になりますが、**このモードではご自身で安全にご注意ください。問題が発生した場合は自己責任となります**。
2. 電極プラグは奥までしっかり挿入してください。挿入が不十分だと出力されません。
3. 心臓、頭部、胴体などのコア部位での使用、またはこれらの部位に電流を流す行為は禁止です。
