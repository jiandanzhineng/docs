# プレイ一覧

> ⚠️ 一人プレイの前に、まず [安全上の注意](/docs/player/solo-safety)をお読みください
>
> 🛒 デバイスの紹介と購入は [デバイス紹介&購入](/docs/#设备介绍购买)をご覧ください

## クライアントダウンロード

ダウンロード・インストールとデバイス接続については [クイックスタート](/docs/start)をご覧ください。

## プレイチュートリアル

| プレイ | 必要なデバイス / 機能 | ひとこと説明 |
| --- | --- | --- |
| [寸止めシリーズの選び方](/docs/player/edging) | 寸止め総合デバイス | 3つの寸止めプレイの違いと選び方のアドバイス |
| [ホスト内蔵寸止め（寸止め+肛門引き締め）](/docs/player/cunzhi01) | 寸止め総合デバイス（気圧+振動+電気パルス） | 閾値まで継続的に刺激し、エッジ状態を維持 |
| [気圧寸止めプレイ（3段階アップグレード版）](/docs/player/cunzhi3step) | 寸止め総合デバイス、自動ロック/OSR6はオプション | 気圧が臨界値を超えると電撃トリガー。平穏-中期-エッジ-クールダウンのサイクル |
| [気圧急変寸止めプレイ](/docs/player/surge-edging) | 寸止め総合デバイス | 短時間の気圧上昇でトリガー。中間圧力は毎ラウンド自動補正 |
| [肛門引き締めトレーニングプレイ](/docs/player/kegel-training) | 寸止め総合デバイス | リラックス-引き締めサイクル検出。怠けると電気パルスでお知らせ |
| [つま先立ちペナルティプレイv2](/docs/player/tiptoe-v2) | 寸止め総合デバイス、自動ロックはオプション | つま先立ちを維持し、かかとが着地したらペナルティ |
| [つま先立ち肛門引き締めトレーニング](/docs/player/tiptoe-kegel) | 寸止め総合デバイス | 肛門引き締めとつま先立ちを同時に維持する姿勢トレーニング |
| [水飲み・液体回収アンロックプレイ](/docs/player/drink-pee-unlock) | 電子はかり、電気パルス/自動ロックはオプション | 目標量の水を飲むか液体を回収するとアンロック、またはタイムアウトでアンロック |
| [腕立て伏せ（おそらく）検出トレーニングゲーム](/docs/player/pushup-game) | 距離センサー、寸止めデバイス/自動ロックはオプション | 距離センサーで腕立て伏せ回数を判定 |
| [扇貝単語暗記電撃](/docs/player/shanbay-shock) | 電気パルスデバイス | 単語を間違えると電撃される単語暗記プレイ |

## プレイ説明

- 寸止めシリーズの選び方のアドバイスは [寸止めプレイの選び方](/docs/player/edging)をご覧ください
- 第1世代デバイスの旧チュートリアルはサイドバーの「過去のゲーム説明」をご覧ください
