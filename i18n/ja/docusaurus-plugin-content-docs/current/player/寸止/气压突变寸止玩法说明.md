# 気圧急変寸止めプレイ説明

## 概要

気圧の変化に応じて自動的に振動を調整する寸止めプレイです：平穏時には徐々に強くなり、気圧の急上昇を検出すると振動を停止します。圧力が戻ってクールダウンしたら、次のラウンドを開始します。

3段階寸止めとの比較では、平穏期、中期、エッジ期、クールダウンのサイクルは共通ですが、トリガー方式を**短時間での気圧上昇幅**に変更し、トリガーのたびに中間圧力を自動補正します。これにより、ゆっくりしたエア漏れなどのベースライン変動が固定閾値に与える影響を軽減します。

| 比較項目 | 3段階寸止め | 気圧急変寸止め |
| --- | --- | --- |
| エッジ期への移行 | 気圧が設定した臨界気圧に到達 | 最近の一定期間の圧力ピークが直前の平均圧力より設定幅だけ高い |
| 圧力設定 | 中間圧力と臨界気圧を手動設定 | 急変ウィンドウと上昇閾値を調整。中間圧力は各ラウンドで自動補正 |
| 調整の重点 | 固定圧力値が自分に合っているか | 急変判定が敏感すぎるか鈍すぎるか |

[3段階寸止めプレイ説明](/docs/player/cunzhi3step)

本文のパラメータはゲーム **1.1.2** のデフォルト設定に基づいています。気圧の変化はあくまでプログラムの判定信号であり、実際の身体状態を直接表すものではありません。

:::caution 終了前ブースト期
デフォルトでは最後の **60 秒**は気圧による寸止めトリガーも中期の弱体も行われず、設定上限まで徐々に強化されます。ゲーム全体で寸止めサイクルを維持したい場合は、開始前に「終了前ブースト期」を **0 秒**に設定してください。
:::

## 必要なデバイス

| デバイスマッピング | 必須か | 役割 |
| --- | --- | --- |
| 気圧センサー | はい | リアルタイムの気圧読み取り値を提供 |
| TD01刺激デバイス | はい | ゲーム目標強度で振動を制御 |
| 電撃ペナルティデバイス | いいえ | エッジ期に電気パルスを発動 |
| 自動ロック | いいえ | ゲーム開始時にロック、正常終了時にアンロック |

寸止め総合デバイスを使用する場合、気圧、振動、電撃の各スロットに、対応する機能を持つ同じデバイスを選択できます。「TD01刺激デバイス」はゲーム内のマッピング名です。電撃や自動ロックをマッピングしなくても、気圧と振動のサイクルは実行できます。

## 使い方 {#use_instruction}

1. デバイスの組み立てを完了し、正式に装着する前に気圧読み取り値と振動制御が正常であることを確認します。
2. クライアントをインストールし、デバイスに接続します。
3. クライアントのゲームライブラリで「気圧急変寸止め」を選択し、気圧センサーと振動デバイスをマッピングします。必要に応じて電撃、自動ロックもマッピングします。
4. ゲーム時間、最大強度、終了前ブースト期を有効にするかを設定します。急変検出はデフォルトの **500 ミリ秒ウィンドウ、1 kPa 上昇閾値**のままにしておくとよいです。
5. ゲームを開始し、圧力曲線とフェーズ変化を観察し、実際のトリガー状況に応じてパラメータを調整します。

## ゲームの流れ

**平穏期に徐々に強化 → 中間圧力到達後に強度を調整 → 気圧急変時に振動停止 → 圧力が戻るかタイムアウト → クールダウン → 平穏期に戻る。**

気圧急変は平穏期でも直接トリガーでき、中期を経由する必要はありません。

### 1. 平穏期

ゲームは強度ゼロから始まり、デフォルトで毎秒 **2** ずつ強化、最大強度は **50** です。圧力が「中間圧力」に達すると中期に入り、気圧急変を検出すると直接エッジ期に入ります。

### 2. 中期刺激

現在の圧力に応じて目標強度を下げます：デフォルトでは「中間圧力」から「中間圧力 + 1 kPa」の間で、目標強度は **20** から徐々に **5** まで低下します。それより高い圧力では下限を維持します。

例えば中間圧力が **30 kPa** で急変がトリガーされていない場合、30 kPa は目標強度20、30.5 kPa は12.5、31 kPa 以上は5に対応します。実際の出力は、最大強度、強化速度、送信間隔にも影響されます。

圧力が中間圧力を下回ると平穏期に戻ります。急変を検出するとエッジ期に入ります。

### 3. エッジ寸止め

エッジ期に入ると振動がゼロになり、エッジトリガーが1回記録されます。電撃デバイスがマッピングされている場合は、電気パルスも1回発動します。デフォルト設定は **20 V、3 秒**です。

以下のいずれかの条件を満たすとクールダウンに入ります：

- 現在の圧力が「トリガー時に記録された直前のウィンドウの平均圧力 + 0.2 kPa」未満。
- エッジ期が最長時間を超えた（デフォルト **5 秒**）。

例えばトリガー前の平均圧力が30 kPa であれば、30.2 kPa 未満に戻ればクールダウンに入れます。圧力が戻らないままの場合も、最長時間に達するとクールダウンに入ります。

### 4. クールダウン遅延

振動はゼロのまま、デフォルトで **5 秒**間待機します。この間、新しい急変の検出は行われず、クールダウン中の最低圧力を記録し、次のラウンドの自動補正に使用します。

クールダウンが終了するとまず平穏期に戻り、その後圧力に応じて中期に入るかを決定します。強度の回復は現在の圧力と中間圧力の差を参照し、強化速度の制限も適用されます。

### 5. ブースト期と終了

デフォルトでは最後の60秒はブースト期に入り、現在の中期、エッジ期、またはクールダウンを優先的に終了し、平穏期の強化ルールで継続的に強度を上げます。**この時、気圧急変は寸止め停止をトリガーしません。**

ゲーム時間が終了すると振動と電気パルスが停止し、マッピングされた自動ロックにアンロックコマンドを送信します。ブースト期の時間がゲーム全体の時間以上である場合、ゲームは最初からブースト期に入ります。

## 気圧急変の判定方法

デフォルトでは直近1秒を2つの連続する0.5秒ウィンドウに分割します：

- **前のウィンドウ**：その前の0.5秒の平均圧力を取ります。
- **現在のウィンドウ**：直近0.5秒の最高圧力を取ります。

「現在のウィンドウの最高圧力 - 前のウィンドウの平均圧力」が **1 kPa** に達し、かつこの比較条件が少なくとも **100 ミリ秒**連続して成立した場合、エッジ期がトリガーされます。

例えば前のウィンドウの平均が30 kPa、現在のウィンドウの最高が31.2 kPa であれば、差は1.2 kPa でデフォルト閾値を超えています。最短継続時間を満たせばトリガーされます。ここで継続するのはウィンドウ比較条件であり、すべてのサンプリング点が31.2 kPa に達する必要はありません。

そのため、**ゆっくり高圧まで上がっても必ずしもトリガーされず、低圧下での急上昇でもトリガーされることがあります**。

## 中間圧力の自動補正

中間圧力の初期値は **50 kPa** です。エッジ期に入るたびに、以下の値から最大値を新しい中間圧力として取ります：

- 今回のトリガーピークから「中間圧オフセット」を引いた値（デフォルトで **1 kPa** を減算）。
- 前回のクールダウン中の最低圧力に **1 kPa** を加えた値。
- 最低値 **1 kPa**。

例えば今回のピークが31.2 kPa、前回のクールダウン最低圧力が29 kPa であれば、新しい中間圧力は30.2 kPa です。前回のクールダウン最低圧力が30 kPa なら、下限によって中間圧力は31 kPa まで上がります。

インターフェースの「中間圧力微調整」は1回に **0.1 kPa** ずつ増減できますが、次のエッジ期に入ると自動補正が再度行われます。

## 設定説明

以下はプログラムのデフォルト値であり、すべての人に適した強度を意味するものではありません。

### 基本と急変判定

| パラメータ名 | デフォルト値 | 説明 |
| --- | --- | --- |
| ゲーム時間 | 20 分 | ゲーム全体の継続時間 |
| 終了前ブースト期 | 60 秒 | 最終段階で継続的に強化し、寸止めをトリガーしなくなります。0に設定するとオフ |
| 急変検出ウィンドウ | 500 ミリ秒 | 各ウィンドウの幅。2つのウィンドウで直近1秒をカバー |
| 急変上昇閾値 | 1 kPa | 現在のウィンドウのピークと前のウィンドウの平均の最小差 |
| 急変最短継続 | 100 ミリ秒 | ウィンドウ比較条件が連続して成立する必要がある時間 |
| 中間圧オフセット | 1 kPa | 自動補正時にトリガーピークから減算する圧力 |
| エッジ期最長時間 | 5 秒 | 圧力が戻らない場合、タイムアウトでクールダウンに入ります |
| クールダウン遅延 | 5 秒 | エッジ期後にゼロ振動を維持する時間 |
| 音声プロンプト | オン | 開始、フェーズ切替、終了などのイベントを読み上げます |

### 強度とオプションの電撃

| パラメータ名 | デフォルト値 | 説明 |
| --- | --- | --- |
| TD01最大強度 | 50 | ゲーム強度の上限。設定範囲は1から100 |
| 平穏期緩やか上昇 | 毎秒2 | 平穏期とブースト期の目標強度増加量 |
| 強度上昇上限 | 毎秒2 | 実際の強度が増加する際の速度制限。減少には適用されません |
| 中期強度下限 | 5 | 圧力が「中間圧力 + オフセット」に達した後の目標強度 |
| 中期強度上限 | 20 | 圧力が中間圧力に等しい時の目標強度。総上限を超えることはできません |
| 強度ランダム変動 | 0% | 平穏期の目標強度のランダム変化幅。0はオフ |
| 強度送信間隔 | 2000 ミリ秒 | 通常の強度コマンドの送信間隔。ゼロ停止はこの間隔を待ちません |
| 電撃強度 | 20 V | 電撃デバイスがマッピングされている場合、エッジ期に使用される電圧 |
| 電撃継続 | 3 秒 | 1回の電気パルスの継続時間 |

## インターフェースと調整

- **圧力曲線**：青い実線は圧力、赤い破線は振動強度、オレンジの破線は中間圧力。緑の点はトリガーピーク、赤い点はエッジフェーズの圧力サンプルを示します。
- **一時停止 / 再開**：一時停止中は振動を停止しますが、気圧の表示は継続します。再開後、急変ウィンドウを再収集します。
- **+10 強度**：現在の目標値を一時的に変更しますが、以降も自動ルールによって再計算されます。最大強度の上限は上がりません。
- **電撃**：設定された電圧と継続時間で電気パルスを1回手動発動します。電撃デバイスのマッピングが必要です。
- **回数とログ**：エッジトリガー、フェーズ切替、最近のトリガーピークなどの記録を確認します。

**一時停止は予定の終了時間を延長せず、自動アンロックや既に開始された電気パルスを中断しません。** 開始された電気パルスは設定時間通りに終了します。一時停止を全デバイスの緊急停止として扱わないでください。

調整の参考：

- **頻繁に誤トリガーする**：まずエア管の接続と読み取り値が安定しているか確認し、次に「急変上昇閾値」を適度に上げるか「急変最短継続」を延ばします。
- **明らかな変化でもトリガーしない**：気圧読み取り値が継続的に更新されているか、かつ現在クールダウンやブースト期にないことを確認し、「上昇閾値」を適度に下げます。
- **停止時間が足りない**：「クールダウン遅延」を増やします。「エッジ期最長時間」は圧力が戻るのを待つ上限であり、固定の休憩時間ではありません。
- **最後に継続強化したくない**：開始前に「終了前ブースト期」を0秒に設定します。

## 安全な使用について

正式に装着する前にデバイス制御が正常であることを確認し、低強度・短時間から始めてください。不快感がある場合は直ちに停止してください。電気パルスの使用と装着の要件については、既存のデバイスチュートリアルに従い、電流を心臓、頭部、または胴体に流さないでください。

[デバイス装着と電気パルスに関する注意事項](/docs/device/cunzhi01/assembly)

自動ロックに接続する前に、プログラム終了時の自動アンロックに頼らない独立した脱出手段があることを確認してください。
