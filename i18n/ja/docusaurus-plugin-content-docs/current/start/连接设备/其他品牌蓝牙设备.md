# 他社 Bluetooth デバイスの接続

自社デバイスのほか、クライアントは以下のサードパーティ製 Bluetooth デバイスもサポートしています。サードパーティ製デバイスはすべて **Bluetooth ダイレクト接続**で、WiFi / ホットスポットは使用しません。

## 対応デバイス

「実機確認済み」= 実機で連携検証済み。「理論対応」= プロトコル実装済みでアドバタイズ名/サービスで識別可能。実機検証はまだで、一部のモデルで認識しない可能性があります。

| ブランド / モデル | クライアント表示名 | 機能 | スマホ | PC | 対応状況 |
| --- | --- | --- | --- | --- | --- |
| DG-LAB 郊狼（D-LAB、COYOTE、ESTIM などのアドバタイズ名） | Bluetooth体感デバイス | 電撃、波形出力 | ✅ | ✅ | 実機確認済み |
| DG-LAB V3（47L アドバタイズ名） | Bluetooth体感デバイス（ダイレクト版） | 電撃、波形出力 | ✅ | ✅ | 実機確認済み |
| 役次元電撃器（YCY、YOKO、DJ-V2 など） | 電撃型デバイス | 電撃 | ✅ | ✅ | 理論対応 |
| 役次元トイ / モーター類（FJB、TDD など） | モーター型デバイス | モーター制御 | ✅ | ✅ | 理論対応 |
| 役次元オナホール（YCY-FJB-03、「カップ」類） | カップ型デバイス | モーター、振動、加熱 | ✅ | ✅ | 実機確認済み |
| 役次元浣腸機（ENEMA、GLJ、「浣腸」類） | 浣腸型デバイス | ポンプ | ✅ | ✅ | 理論対応 |
| 繁野・啵啵貝（SOSEXY） | 啵啵貝 | 振動、吸引、微弱電流 | ✅ | ✅ | 理論対応 |
| GXP 艾萝机娘二代（XA9935、GXP） | gxp艾萝机娘二代 | モーター | ✅ | ✅ | 理論対応 |
| 標準心拍数ベルト（Polar、TICKR、COOSPO、迈金などの 0x180D デバイス） | 心拍数ベルト | 心拍数報告（入力のみ、出力なし） | ✅ | ✅ | 実機確認済み（H10 類の標準ベルト。メーカーカスタムベルトは認識しないことがあります） |

## スマートフォンでの接続

1. デバイスを起動し、Bluetooth アドバタイズ状態にします。
2. クライアントを開き、「デバイスを追加」または右上のプラスアイコンをタップします。クライアントはアドバタイズ名でサードパーティ製デバイスを自動識別します。
3. デバイスを選択して「完了」をタップします。追加が成功すれば接続済みです。

## PC での接続

PC クライアントのサードパーティ製デバイスは「デバイス管理 → ブランドデバイス」タブで管理します：

1. PCの Bluetooth がオンで、デバイスがアドバタイズ状態であることを確認します。
2. 「デバイス管理 → ブランドデバイス」を開きます：デフォルトで自動接続がオンで、認識済みデバイスをスキャンすると自動的に接続します。手動でスキャンをクリックし、リストからデバイスを選択して接続することもできます。

## 注意

- **心拍数ベルトは心拍数の報告のみ**で、制御可能な出力はありません。刺激/電撃デバイスとしては使えません。
- 役次元デバイスは PC 側で Bluetooth ダイレクト接続のほかにブリッジ方式も対応しています。繁野啵啵貝、GXP は Bluetooth ダイレクト接続のみ対応しています。
- 電撃類デバイス（DG-LAB、役次元電撃器）は接続後、自社電撃デバイスと同様にプレイ内で電撃出力としてマッピングできます。
