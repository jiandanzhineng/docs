# Bluetooth ダイレクト接続（スマートフォン）

スマートフォンクライアントでは、日常のデバイス操作は Bluetooth ダイレクト接続を使い、WiFi は不要です。デバイスを起動すると青いランプが点滅します。スマートフォンの Bluetooth をオンにし、以下の手順で追加してください：

1. デバイスを起動します。この時点でデバイスは青いランプが点滅しているはずです（点滅しない場合はまず充電してください）。
2. クライアントを開き、「デバイスを追加」または右上のプラスアイコンをタップします。
   ![APPホーム画面スクリーンショット ##h40vh##](../img/client/app.jpg)
3. 「デバイスを追加」をタップします。
   ![デバイスを発見 ##h40vh##](../img/client/finddevice.jpg)
4. 「完了」をタップします。
   ![デバイスを追加 ##h40vh##](../img/client/adddevice.jpg)
5. 追加が成功すれば接続済みです。接続成功後、青いランプは数秒間点灯した後に消灯します。
   ![完了 ##h40vh##](../img/client/finish.jpg)

:::note
デバイスの Bluetooth と WiFi はどちらか一方のみです。ネットワーク設定またはホットスポットに接続すると、デバイスの Bluetooth は自動的にオフになります。Bluetooth ダイレクト接続が必要な場合は、デバイスを BLE モードに切り替えてください。
:::
