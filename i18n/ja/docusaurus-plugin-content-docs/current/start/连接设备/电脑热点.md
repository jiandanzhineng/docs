# PCホットスポット（PCからデバイスに接続）

PCクライアントから自社デバイスを操作するには、WiFi / LAN経由でのみ可能で、スマートフォンのような Bluetooth ダイレクト接続はできません。PCの Bluetooth は[他社デバイス](/docs/start/connect/brand-devices)（DG-LAB など）専用です。最も簡単な方法は、PCでホットスポットを有効にすることです。デバイスが自動的に接続します。

1. PCのホットスポットを有効にし、WiFi名を `easysmart`、パスワードを `11111111`、バンドを **2.4G** に設定します。
2. デバイスが WiFi に接続したのにクライアントにデバイスが表示されない場合は、PCのファイアウォールを無効にしてください。
3. デバイスを起動します。起動後約15〜30秒で自動的にPCに接続されます。

## 注意

- デバイスが以前 5G WiFi に接続していた場合、2.4G に設定しても 5G バンドのままのことがあります。その場合は、デバイスを一度 2.4G WiFi（または有線LAN）に接続してから再試行してください。
- デバイスはデフォルトで `easysmart` という名前でパスワード `11111111` の WiFi に自動接続します。ネットワーク設定をしたくない場合は、このデフォルトWiFiをそのまま使用できます。

PCホットスポットが使えない環境では、デバイスを[自宅のWiFiにネットワーク設定](/docs/start/connect/pc-home-wifi)し、PCはLAN経由で接続します。
