# 接続方法の選び方

デバイスには Bluetooth と WiFi の2つの接続方法があり、どちらか一方のみ選択できます。ネットワーク設定またはホットスポットに接続すると、デバイスの Bluetooth は自動的にオフになります。Bluetooth ダイレクト接続に戻るには、デバイスを BLE モードに切り替えてください。

| 方法 | おすすめの人 | 前提条件 | 注意 |
| --- | --- | --- | --- |
| [Bluetooth ダイレクト接続（スマートフォン）](/docs/start/connect/ble) | スマートフォンで日常プレイ | デバイスの青ランプ点滅、スマートフォンの Bluetooth オン | ネットワーク設定またはホットスポット接続後は Bluetooth がオフになるため、BLE モードに切り替えが必要 |
| [PCホットスポット](/docs/start/connect/hotspot) | PCクライアントでプレイ | PCで 2.4G ホットスポットを起動でき、名前を `easysmart`、パスワードを `11111111` に設定 | PCクライアントから自社デバイスを制御するには WiFi / LAN のみ。PCの Bluetooth は[他社デバイス](/docs/start/connect/brand-devices)（DG-LAB など）専用 |
| [自宅WiFiへのネットワーク設定](/docs/start/connect/pc-home-wifi)（スマホでもPCでも可） | PCでホットスポットが起動できない、スマートフォンからの遠隔操作、ファームウェアアップグレード、複数デバイスオンライン | 自宅に 2.4G WiFi、ルーターが mDNS 対応 | ネットワーク設定は 2.4G WiFi のみ。設定後は Bluetooth が自動オフ |
| スマートフォンホットスポット（Android LANサービス方式 A） | ルーターがない環境で Android スマートフォンを使用 | Android スマートフォン。ホットスポット名を `easysmart`、パスワードを `11111111` に設定 | Android のみ。デバイスは自動的にゲートウェイ Broker に接続します。iPhone は固定名ホットスポットに対応していないため、ルーター設定のみ利用可能 |

デバイスはデフォルトで `easysmart` という名前でパスワード `11111111` の WiFi に自動接続します。ネットワーク設定をしたくない場合は、このデフォルトWiFiをそのまま使用できます。

## おすすめ

- **スマートフォンで日常プレイ**：[Bluetooth ダイレクト接続](/docs/start/connect/ble)を使います。デバイスを起動すればすぐに遊べます。
- **PCでプレイ**：PCで [2.4G ホットスポット](/docs/start/connect/hotspot)を起動します。ホットスポットが使えない場合は[自宅WiFiへのネットワーク設定](/docs/start/connect/pc-home-wifi)をご利用ください。
- **スマートフォンからの遠隔操作、ファームウェアアップグレード、複数デバイスオンライン**：ネットワーク設定またはスマートフォン側の「LANサービス」を使い、デバイスを WiFi に接続します。
