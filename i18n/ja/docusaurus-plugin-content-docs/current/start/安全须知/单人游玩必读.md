# ソロプレイ必読

一人でのプレイはより自由ですが、ご自身の安全により責任を持つ必要があります。開始する前に必ずこのページを最後までお読みください。特に**自動ロック**に関する注意事項をご確認ください。

## ⚠️ 安全第一：脱出手段

**一人プレイは必ず安全に注意し、脱出手段を用意してください。脱出手段がない場合は一人プレイをしないでください。**

デバイスはネットワークとプログラムで制御されるため、誰も100%の安全を保証できません（回線断、プログラムの停止、デバイスの故障など）。一人でプレイしているときにロックされて他の人に連絡がつかない場合、脱出できるのは自分だけです。

必ずデバイス以外の脱出手段を用意してください。例えば手にハサミをぶら下げ、必要な時にロープを切るなどです。

> 「デバイスが自動的に開錠する」ことにすべての希望を託さないでください——それは最後のセーフティネットであり、脱出手段ではありません。

## 自動ロックの注意事項

自動ロック（シンプルスマートロック端末）は一人での自己拘束プレイで最もよく使われるデバイスです。以下の挙動を必ずご理解ください：

1. **低電量自動アンロック**：電量が20%を下回ると自動的にアンロックされ、あなたが閉じ込められるのを防ぎます。これは最後のセーフティネットであり、これに頼った脱出はしないでください。
2. **長押し自動アンロック**：ロック本体のボタンを約 **300 秒**長押しすると、ロックは自動的に強制アンロックされます。
3. **強制アンロック後はロックできなくなります**：一度強制アンロックすると、このロックは**再びロックできなくなります**。最後の手段として使ってください——使うとロックは「壊れた」状態になり、工場への返送修理が必要です。

> 使用前に、ロック本体のボタンの位置を確認し、手が届くことを確認してください。

## キーでゲームを開始（一人での自己拘束）

一人での自己拘束では、まず自分をロックし、その後デバイスのキーを押してゲームを開始できます。スマートフォンとパソコンの具体的な手順は [キーで開始](/docs/player/key-start)をご覧ください。

## デバイスの安全

以下の安全事項は、センサーや電気パルス機能を持つすべてのデバイスに適用されます。各プレイページでは繰り返し説明しません：

- 心臓、頭部、胴体などのコア部位での電気パルス機能の使用、またはこれらの部位に電流を通す行為は禁止です。電気パルスパッドは太ももの内側のみに貼り付けてください。
- 人体使用時の電圧は 36V を超えてはいけません。電気パルスの強度は低い段階から徐々に上げてください。
- アナルプラグなどのセンサーは完全防水ではありません。水中で洗わないでください。洗浄後は密閉袋に入れて保管し、長期間乾燥した環境に置くと表面がひび割れます。
- 体調不良時や、心臓病、てんかんなどの基礎疾患がある場合は本製品の使用を禁止します。本製品は18歳以上の成人のみ使用可能です。
- 低強度・短時間から始めることをお勧めします。途中で体調不良を感じた場合は直ちに中止してください。
