# キーで開始（一人での自己拘束）

「キーで開始」は一人プレイ専用の開始方法です：**まず自分をロックし、その後ロック上のキーを押してゲームを開始**できます。他の人にスタートを押してもらう必要はありません。

> 一人プレイの前に[安全上の注意](/docs/player/solo-safety)をお読みください。デバイス以外の脱出手段があることを確認してください。

操作方法はスマートフォンとパソコンで同じで、入口だけが少し異なります：

## スマートフォンでの操作

1. 遊びたいゲームに入り、デバイスマッピングとパラメータ設定を完了します。
2. 設定ページの下部で **「キーで開始」**をタップします。
3. 「キートリガー元を選択」がポップアップするので、ドロップダウンから**キー付きのオンラインデバイス**（例：自動ロック）を選択します。
4. **「1回テスト」**をタップし、実際にロックのキーを1回押します。**「キーを受信しました」**と表示されれば接続確認完了です。
5. **「確認」**をタップし、「まもなく開始」の待機ページに入ります。
6. この時点でゲームはまだ開始していません。**ロックのキーを1回押す**と、ゲームが正式に開始されます。

## パソコンでの操作

1. 遊びたいゲームに入り、デバイスマッピングとパラメータ設定を完了します。
2. 設定ページの下部で、**「開始」ボタンの横**にある **「デバイスキーで開始」**をクリックします。
3. 「キートリガー元を選択」がポップアップするので、ドロップダウンから**キー付きのオンラインデバイス**（例：自動ロック）を選択します。
4. **「1回テスト」**をクリックし、実際にロックのキーを1回押します。**「キーを受信しました」**と表示されれば接続確認完了です。
5. **「確認」**をクリックし、実行ページの「まもなく開始」待機ページに入ります。
6. この時点でゲームはまだ開始していません。**ロックのキーを1回押す**と、ゲームが正式に開始されます。

> 待機ページには「キャンセル」と「強制開始」ボタンがあります：遊びたくなくなったらキャンセルして戻れます。キーを待ちたくない場合は直接強制開始も可能です。
>
> 「キーテストが通過」した後のみ確認して待機状態に入れるのは、自分をロックしたのにキーが反応せず、ゲームも開始できないという状況を避けるためです。
