# はじめてのご利用

:::info
一人プレイの前に、まず [安全上の注意](/docs/player/solo-safety)をお読みください：一人プレイにはデバイス以外の脱出手段が必要です。
:::

はじめてのご利用は以下の3ステップで進めてください。

## 1. クライアントをダウンロード・インストール

スマートフォンには[Androidクライアント](/docs/player/new-phone-client)、PCには [Windows クライアント](/docs/player/new-phone-client#pc)をインストールします。iPhone、HarmonyOS はそれぞれ [iOS クライアント](/docs/player/new-phone-client#ios)、[HarmonyOS クライアント](/docs/player/new-phone-client#鸿蒙客户端)をご覧ください。

## 2. デバイスに接続

スマートフォンでの日常利用は Bluetooth ダイレクト接続がおすすめです：デバイスを起動して青ランプが点滅したら、クライアントを開き「デバイスを追加」をタップするだけです。PCを使う場合や WiFi が必要な場合は、まず[接続方法の選び方](/docs/start/connect)をご覧ください。

## 3. プレイを選んで開始

[プレイ一覧](/docs/player)を開いて遊びたいプレイを選び、チュートリアルに沿ってデバイスマッピングとパラメータ設定を完了すれば開始できます。
