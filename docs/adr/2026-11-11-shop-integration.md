# 文档与商城互通

- 导航栏加「商城」，页脚官网商城与淘宝店并列。中文链到商城 zh，其他语言链到商城 en。
- 从文档进商城的链接一律带 `ref=docs-<页面>`，用商城现有推广来源统计。
- 商品与教程的对应关系只在文档维护：中文源页 frontmatter 写 `products: [商品slug]`，非中文副本不用写。
- 文档页按该字段在正文后显示「本页用到的设备」卡片（图、名称、去商城），**不显示价格**。
- 构建时导出 `product-docs.json`（商品 slug → 各语言教程标题与网址），供商城商品页、订单页和小程序使用。
- 已有正文里的手写商城链接保留。
