# 简单智能锁定终端

> 逻辑 ID `ZIDONGSUO`。通过 WiFi 无线控制锁定 / 解锁，用于"不玩完不许走"等需要强制约束的玩法。

![锁定终端 ##w30%##](./img/ZGvq049xBaouj3MU/1750851448187-f17fa36f-e863-4896-9329-9b00b6095a9b-531187.png)

## 产品特性

- 无线控制锁定 / 解锁（WiFi / BLE）
- 长按按钮 60 秒强制解锁
- 电量低于 20% 自动解锁（防困）
- 可编程，支持定时控制
- Type-C 充电

## 设备参数

| 项目 | 说明 |
| :--- | :--- |
| 逻辑 ID | ZIDONGSUO |
| 功能 | 自动锁 |
| 控制属性 | open |
| 供电 | 内置电池 + Type-C 充电 |
| 通信 | WiFi (2.4G) / BLE |
