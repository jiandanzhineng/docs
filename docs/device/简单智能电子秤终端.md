# 简单智能电子秤终端（DZC01）

> ⏳ 即将发布，敬请期待

基于 HX711 称重传感器的智能电子秤终端，支持重量实时上报，并带 OLED 显示屏，可下发自定义文字。

## 产品特性

- 高精度称重（HX711 传感器）
- 重量实时上报
- OLED 显示屏，支持自定义两行文字
- 显示开关、对比度、显示模式可调
- 按键触发

## 设备参数

| 项目 | 说明 |
| :--- | :--- |
| 逻辑 ID | DZC01 |
| 功能 | 电子秤（HX711 + OLED） |
| 通信 | WiFi (2.4G) / BLE |
| 固件能力 | weight / display_mode / display_on / display_contrast / line1_text / line2_text / button2 |
