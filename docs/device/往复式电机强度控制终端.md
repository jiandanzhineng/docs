# 往复式电机强度控制终端（炮机控制器）

> 即「炮机控制器」，逻辑 ID `PJ01`。通过 WiFi 无线控制往复式电机（炮机）的强度，可接入寸止玩法作为刺激输出。

## 产品特性

- 无线控制（WiFi / BLE）
- PWM 电机调速，强度 0~255 级
- 外接电源供电（大功率，无内置电池）
- 支持接入寸止玩法联动

## 设备参数

| 项目 | 说明 |
| :--- | :--- |
| 逻辑 ID | PJ01 |
| 功能 | PWM 电机控制（往复式 / 炮机） |
| 控制属性 | power（0~255） |
| 供电 | 外接电源（无电池） |
| 通信 | WiFi (2.4G) / BLE |
