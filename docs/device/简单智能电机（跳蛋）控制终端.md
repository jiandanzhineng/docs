# 简单智能电机（跳蛋）控制终端

> 逻辑 ID `TD01`。通过 WiFi 无线控制电机（跳蛋）的震动强度，可接入多种玩法。

## 产品特性

- 无线控制（WiFi / BLE）
- 震动强度 0~255 级调节
- 支持普通 USB 跳蛋接入
- 大容量电池
- 开源，支持 Python 二次开发

## 设备参数

| 项目 | 说明 |
| :--- | :--- |
| 逻辑 ID | TD01 |
| 功能 | 电机 / 跳蛋控制 |
| 控制属性 | power（0~255） |
| 供电 | 内置大容量电池 + Type-C 充电 |
| 通信 | WiFi (2.4G) / BLE |
