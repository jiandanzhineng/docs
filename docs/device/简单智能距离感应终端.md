# 简单智能距离感应终端

> 逻辑 ID `QTZ`。通过距离传感器检测身体高度 / 动作，用于俯卧撑、踮脚等需要动作判定的玩法。

![距离感应终端 ##w30%##](./img/Qu8mhshxEPagKgZC/1750854320916-7f1d258e-fcde-49d3-b249-d6202d7061cc-516028.png)

## 产品特性

- 距离实时上报（毫米级）
- 双按钮脚踏板触发
- 距离区间（低 / 高带）判定
- Type-C 充电

## 设备参数

| 项目 | 说明 |
| :--- | :--- |
| 逻辑 ID | QTZ |
| 功能 | 距离 / 高度检测 |
| 控制属性 | distance / low_band / high_band / button0 / button1 |
| 供电 | 内置电池 + Type-C 充电 |
| 通信 | WiFi (2.4G) / BLE |
